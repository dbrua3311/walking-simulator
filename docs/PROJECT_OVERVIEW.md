# 프로젝트 범위와 인수인계 분석

사용자 지시가 원문보다 우선한다. 제품명은 Walking Simulator이고 기존 자동차 프로젝트와 완전히 별개다. 원문 마지막의 “설계 및 개발 준비 단계, 코딩은 사용자 지시 후”를 적용한다.

## 기능 분류

아래는 원문에 기초한 기능 수준의 분류다. 기존 자동차 소스를 열어 구조·라이선스·테스트를 조사한 결과가 아니므로 코드 재사용 가능성을 확정하지 않는다. 현재 계획은 새 프로젝트에서 독립 구현하는 것이다.

| 항목 | 새 프로젝트에서의 처리 |
| --- | --- |
| 왼쪽 설정·중앙 시뮬레이션·오른쪽 기록 | 화면 구조 개념 유지 |
| 다중 동시 출발, 세대 진화 | 동일 시간축의 개체별 World로 구현 |
| 부모 선택, 교차, 돌연변이 | 보행 유전자에 맞게 독립 구현 |
| 수동 클릭·드래그·결정완료 | 마지막 자세를 유지하는 레인 선택으로 구현 |
| 자동 부모 선택·연속 진화 | Worker 상태 머신으로 구현 |
| 배속·일시정지·재개 | 고정 dt 유지, 계산 스텝 수만 조절 |
| 금색 챔피언·오라 | 직전 1등의 동일 유전자 1개와 렌더 효과 |
| 고스트 | 실제 몸통·관절 궤적 재생으로 교체 |
| JSON·CSV·그래프 | 보행 지표와 새 형식 버전으로 구현 |
| 트랙·조향·브레이크·랩타임·거리 센서 | 제거, 평지·모터·발 접촉·유효 거리로 교체 |
| 자동차 물리·차량 유전자·체크포인트 보상 | 사용하지 않음 |
| 기존 자동차 저장 파일 | 자동 호환하지 않음, 별도 import 요구 시 후속 설계 |

## 초기 범위

고정 체형의 4족, 8구동 관절, 평지, 20개체, 15초 평가를 초기값으로 제안한다. 개체 수·평가 시간·목표 거리·물리 설정·진화 설정은 실험 설정으로 관리한다. 경사·장애물·체형 진화·신경망·3D·실제 로봇 연결은 초기 범위에 포함하지 않는다.

성공은 결과를 좋게 보이게 만드는 것이 아니라 계산의 재현성, 진화 연산의 진실성, 정지·재개·저장 무결성을 확보하고 측정한 보행 개선 여부를 설명하는 것이다.

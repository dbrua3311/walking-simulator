# 제품 동작 명세

## 화면

왼쪽: 실험 이름, 시드, 개체 수, 평가 시간, 목표 거리, 돌연변이율, 교차율, 부모 수, 배속, 실행·일시정지, 자동 학습 시작·정지, 선택 초기화·결정완료, 저장·불러오기·CSV.

중앙: 동일 축척의 스크롤 가능한 가로 레인. 가까운 다리는 선명하게, 먼 다리는 어둡게 표현한다. 전체 개체를 항상 계산하며 화면 밖 레인만 렌더를 생략한다. 공통 카메라 원점과 축척을 사용해 거리 비교가 가능해야 한다. 레인별 ID·현재 거리·상태를 표시한다.

오른쪽: 현재 세대, 선두, 최고·평균 유효 거리, 최고·평균 보조 적합도, 넘어짐·성공 수, 부모 선택 목록, 최고 기록과 세대별 그래프. 거리와 보조 지표는 축·단위를 구분한다.

## 상태와 조작

상태는 ready, running, paused, selection, error를 구분하고 연속 진화 여부 autoEnabled를 별도로 둔다. paused에는 멈춘 원래 상태를 기록한다.

- 일반 실행은 현재 세대를 이어서 계산한다. 전 개체 종료 시 selection에서 대기한다.
- 수동 선택은 selection에서만 활성화한다. 클릭은 선택/해제, 빈 공간 드래그는 교차하는 개체들의 화면상 몸체·다리 경계 영역을 선택한다. 종료 자세와 카메라를 바꾸지 않는다.
- 클릭 최소 판정 크기는 CSS 24px로 제안한다. 겹침 시 후보 ID 목록을 제공해 개별 선택도 가능하게 한다. 드래그는 영역의 모든 후보를 선택한다. 고스트는 선택 판정에서 제외한다.
- 결정완료는 1개 이상 부모를 선택해야 활성화한다. 하나만 선택하면 해당 부모의 자가 교차와 돌연변이를 허용한다. 직전 1등은 선택과 무관하게 그대로 보존한다.
- 자동 부모 선택 버튼은 현재 순위 상위 후보만 선택하며 결정완료 전 세대를 넘기지 않는다.
- 자동 학습 시작은 paused/running/ready 상태에서 이어서 실행한다. selection 상태라면 현재 완료 세대의 자동 부모로 다음 세대를 만든다. 매 세대 종료마다 자동 선택·진화한다.
- 자동 학습 정지는 autoEnabled를 해제하고 paused로 들어간다. 새 창이나 화면을 띄우지 않는다. 현재 World, 관절, 속도, 평가 tick, 통계, 난수 상태, 선택을 메모리에 보존한다. 일반 실행·자동 시작 모두 같은 상태에서 재개한다.
- 설정 변경은 다음 세대 경계에만 적용한다. 지면·체형 등 평가 조건 변경은 새 실험으로 분리하고 이전 통계와 섞지 않는다. 배속·표시 옵션은 즉시 적용 가능하다.

## 순위와 기록

정렬 키는 유효 전진 거리 내림차순, 해당 거리 최초 도달 tick 오름차순, 로봇 ID 오름차순이다. 비교용 거리는 0.001m 단위 정수로 정의하고 원본 부동소수점 거리도 보존한다. 보조 적합도는 공식 순위를 뒤집지 않는다.

넘어져도 그 이전의 유효 전진 거리가 가장 크면 1등이다. 1세대에는 챔피언이 없으며 이후 직전 1등 유전자 사본 정확히 하나를 금색으로 표시한다. 다른 자식이 우연히 같은 유전자를 가져도 금색 표시는 champion 플래그로 하나만 관리한다.

## 파일 저장

초기 버전은 완료 세대 경계 저장을 지원한다. 주행 중 저장 요청은 현재 상태를 바꾸지 않고 “현재 세대 종료 후 저장”으로 예약한다. 일시정지 중 즉시 저장 불가 사유와 예약 상태를 표시한다. 종료 경계에서 진화 전에 체크포인트를 만든다.

JSON 필드: formatVersion, appVersion, engineVersion, controllerVersion, experimentName, generation, config(체형·물리·평가·GA), population(ID·유전자·부모 계보·챔피언), completedResults, selectedParentIds, history, allTimeBest, ghost, rngState, evaluationTick, phase, autoEnabled. 완료 체크포인트는 selection 상태로 재개하고 자동 실행은 사용자가 누른 뒤 시작한다. 원래 모드는 메타데이터로 유지한다.

검증은 파일 용량, 버전, 유한 수치, 범위, 개체 수, 유전자 길이, 고유 ID·참조, 통계와 궤적 길이까지 수행한다. 임시 모델에 전체 검증·복원한 뒤 현재 실험과 원자적으로 교체한다. 실패 시 현재 메모리 상태는 유지한다.

CSV 열: generation, bestDistanceM, meanDistanceM, bestFitness, meanFitness, fallenCount, successCount, bestRobotId. 최고 보조 적합도는 거리 1등의 보조 점수가 아니라 해당 세대 보조 점수의 최댓값이다.

브라우저 다운로드 기본 위치가 메인 디스크일 수 있다. 실험 저장은 USB 폴더를 명시적으로 선택하는 파일 선택기를 우선 검토하고 미지원 브라우저에서는 저장 위치 확인을 안내한다. 브라우저가 임의의 Linux 절대 경로로 자동 저장할 수 있다고 가정하지 않는다.

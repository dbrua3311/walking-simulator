# 제품 동작 명세

## 화면

왼쪽: 실험 이름, 시드, 개체 수, 평가 시간, 목표 거리, 돌연변이율, 변형 크기, 교차율, 부모 수, 배속, 실행·일시정지, 자동 학습 시작·정지, 선택 초기화·결정완료, 저장·불러오기·CSV.

중앙: Three.js 3D 관찰 화면. 기본은 20개체를 한 화면의 5×4 관찰 칸으로 동시에 표시한다. 각 칸의 실제 물리 계산은 독립적이고, ID·거리·부모·변형 개수를 보여 준다. 개체 상세와 전체 동시 보기를 제공하고 카메라 회전·확대·이동을 지원한다. 현재 선두 자동 관찰 또는 특정 로봇을 선택한다. 13강체·12관절의 실제 자세와 발별 접지·높이·걸음 수를 표시한다. 모든 개체의 물리는 보이는 개체와 무관하게 동시에 계산한다. 단순 이동과 보행 인정 거리를 구분한다.

오른쪽: 현재 세대, 선두, 최고·평균 유효 거리, 최고·평균 보행 점수, 넘어짐·성공 수, 부모 선택 목록, 최고 기록과 세대별 그래프. 거리와 보조 지표는 축·단위를 구분한다.

## 상태와 조작

상태는 ready, running, paused, selection, error를 구분하고 연속 진화 여부 autoEnabled를 별도로 둔다. paused에는 멈춘 원래 상태를 기록한다.

- 일반 실행은 현재 세대를 이어서 계산한다. 전 개체 종료 시 selection에서 대기한다.
- 수동 선택은 selection에서만 활성화한다. 클릭은 선택/해제, 전체 보기에서 드래그는 교차하는 관찰 칸을 선택하고, 상세 보기에서는 몸체·다리 투영 경계 영역으로 선택한다. 종료 자세와 카메라를 바꾸지 않는다.
- 클릭 최소 판정 크기는 CSS 24px로 제안한다. 겹침 시 후보 ID 목록을 제공해 개별 선택도 가능하게 한다. 드래그는 영역의 모든 후보를 선택한다. 고스트는 선택 판정에서 제외한다.
- 결정완료는 1개 이상 부모를 선택해야 활성화한다. 기본은 선택한 부모를 순위순으로 돌아가며 복사하고 작은 돌연변이를 준다. 교차는 기본 0%이고 켜면 서로 다른 두 부모를 조합한다. 하나만 선택하면 복사·돌연변이만 수행한다. 직전 1등은 선택과 무관하게 그대로 보존한다.
- 자동 부모 선택 버튼은 보행 점수와 동작 다양성 후보를 선택하며 결정완료 전 세대를 넘기지 않는다.
- 자동 학습 시작은 paused/running/ready 상태에서 이어서 실행한다. selection 상태라면 현재 완료 세대의 자동 부모로 다음 세대를 만든다. 매 세대 종료마다 자동 선택·진화한다.
- 자동 학습 정지는 autoEnabled를 해제하고 paused로 들어간다. 새 창이나 화면을 띄우지 않는다. 현재 World, 관절, 속도, 평가 tick, 통계, 난수 상태, 선택을 메모리에 보존한다. 일반 실행·자동 시작 모두 같은 상태에서 재개한다.
- 설정 변경은 다음 세대 경계에만 적용한다. 지면·체형 등 평가 조건 변경은 새 실험으로 분리하고 이전 통계와 섞지 않는다. 배속·표시 옵션은 즉시 적용 가능하다.

## 순위와 기록

부모·엘리트·실시간 순위는 jumped/invalid 뒤로, 보행 점수·0.001m 보행 거리 구간·접지 전진·안정 지지 시간 내림차순, ID 오름차순이다. 자동 부모는 유효 후보가 있으면 점프·계산 오류를 제외한다. 종료 시간은 우선 순위가 아니다. 거리 통계와 고스트는 별도 거리 순위를 유지한다.

1세대에는 챔피언이 없으며 이후 직전 보행 점수 1등 유전자 사본 하나를 금색으로 표시한다. 다른 자식의 유전자가 같아도 champion 플래그로 구분한다.

## 파일 저장

초기 버전은 완료 세대 경계 저장을 지원한다. 주행 중 저장 요청은 현재 상태를 바꾸지 않고 “현재 세대 종료 후 저장”으로 예약한다. 일시정지 중 즉시 저장 불가 사유와 예약 상태를 표시한다. 종료 경계에서 진화 전에 체크포인트를 만든다.

JSON 필드: formatVersion, appVersion, engineVersion, controllerVersion, evolutionVersion, experimentName, generation, config(체형·물리·평가·GA), population(ID·유전자·부모 계보·챔피언), completedResults, selectedParentIds, history, allTimeBest, ghost, rngState, evaluationTick, phase, autoEnabled. 완료 체크포인트는 selection 상태로 재개하고 자동 실행은 사용자가 누른 뒤 시작한다. 원래 모드는 메타데이터로 유지한다.

검증은 파일 용량, 버전, 유한 수치, 범위, 개체 수, 유전자 길이, 고유 ID·참조, 통계와 궤적 길이까지 수행한다. 임시 모델에 전체 검증·복원한 뒤 현재 실험과 원자적으로 교체한다. 실패 시 현재 메모리 상태는 유지한다.

CSV 열: generation, bestDistanceM, meanDistanceM, bestFitness, meanFitness, fallenCount, successCount, bestRobotId, stage, maxSupportTime, maxFootCount, maxWalkingTime, qualifiedCount. 최고 보행 점수는 해당 세대 전체 개체 점수의 최댓값이다.

브라우저 다운로드 기본 위치가 메인 디스크일 수 있다. 실험 저장은 USB 폴더를 명시적으로 선택하는 파일 선택기를 우선 검토하고 미지원 브라우저에서는 저장 위치 확인을 안내한다. 브라우저가 임의의 Linux 절대 경로로 자동 저장할 수 있다고 가정하지 않는다.

3D v5 파일은 xyz·quaternion을 가진 13강체, 12관절 각도, 4발의 실제 접촉·높이·걸음·미끄러짐을 저장한다. 이전 v1·v2·v3·v4는 현재 상태를 바꾸지 않고 거절한다. 보행 인정 조건은 ARCHITECTURE.md를 따른다.

기본 돌연변이율은 선택 영역의 유전자별 10%, 변형 크기는 해당 허용 범위의 최대 3%다. 양수 변이율은 자식당 최소 1개 변형을 보장하며 우승 엘리트는 제외한다. 0%는 정확히 복사한다. 각 개체의 birth와 유전자 검사창은 출처 세대·기준 부모 유전자·실제 변경 인덱스를 표시하고 JSON으로 보존한다.

현재 0.6.0은 무작위 541개 신경망 유전자다. 실제 센서와 무작위 주파수의 시간 변화 입력으로 토크를 매 tick 다시 계산한다. 보행 주기·발 경로·자세 보정을 미리 정하지 않고 12관절 토크를 직접 출력한다. 공통 조립 자세로 시작하며 초기 0m·넘어짐을 허용한다. 보행 점수 그래프와 실제 지지 시간을 표시하고 유전자 검사창은 24개씩 페이지와 변경 필터를 제공한다.

평가가 끝난 개체 칸과 해당 상세 화면에는 옅은 회색을 덧씌운다. 회색은 선택을 막지 않으며 마지막 자세와 종료 시간을 유지한다. 전체 일시정지된 active 개체는 회색 처리하지 않는다. 자동 부모는 보행 점수와 동작 다양성으로 N개체를 고른다. 회색 전환 시각은 선발 기준이 아니다. 장기 체공·과도한 높이는 점프 종료하고 네 발 동시 착지는 걸음에서 제외한다.

작은 변이의 약 절반은 임의의 한 관절 출력 연결을, 나머지는 전체 신경망을 대상으로 한다. 변이율 100%는 전체 대상이다. 중간·큰 변이와 새 무작위 탐색 비중은 아래 자동 탐색 확대 기준을 따른다. 새 무작위 개체는 부모 변이와 계보를 구분한다. 수동 부모는 부모 변이 자식에 순위순으로 반영한다.

물리 환경 설정에 관절 점성 감쇠를 제공한다. 각도 목표나 보행 자세는 지정하지 않는다. 새 JSON에는 selectionVersion과 rewardVersion을 필수로 기록하며 이전 평가의 파일을 새 점수와 섞지 않는다.

## 단계별 보행 학습과 검증 (0.6.0)

실험은 균형 유지로 시작하고 3세대 연속 달성 시 다음 세대부터 발 옮기기, 이후 연속 전진으로 넘어간다. 화면에 단계·조건·진행·승급 대기를 표시한다. 점수 내역에서 실제 지지 시간 비례 보상·발 옮김·전진·안정 연속 보행·감점을 확인한다. 화면은 내부 점수×1,000을 표시한다. 기본 수치와 가중치는 README·ARCHITECTURE를 따른다.

자동 부모 5대는 상위 3대와 다른 발 사용/동작 후보 최대 2대를 포함한다. 유효 후보가 없으면 점수순으로 채우고 수동 선택은 유지한다. 보행 점수 그래프는 현재 학습 단계만 표시하며 CSV에는 stage,maxSupportTime,maxFootCount,maxWalkingTime,qualifiedCount를 기존 열 뒤에 추가한다.

전진 후보는 validating에서 세 초기 기울기 조건의 실제 물리를 재평가한다. 일시정지/재개와 예약 저장을 지원한다. 세 조건 모두 통과하면 자동 학습을 멈추고 유전자와 결과를 보존한다. 실패하면 다음 후보를 탐색한다. 점수 상승이나 낮춘 테스트 승급 기준은 보행 성공으로 표시하지 않는다.

v5 체크포인트는 현재 단계·시작 세대·연속 달성 횟수·승급 예약, 점수 내역, 검증 결과와 검증 우승을 보존한다. 이전 v4는 현재 실험을 바꾸지 않고 거절한다. 새 실험의 첫 세대는 항상 무작위다.

## 시간 변화와 탐색 확대 (0.6.0)

시간 주파수·연결 가중치를 무작위로 만들고 유전으로 진화시킨다. 보행 순서·발 경로·자세 보정을 지정하지 않는다. 실패율 70% 또는 같은 단계 5세대 성과 정체 시 일부 자식의 변이율/폭·새 무작위 개체 비중을 늘리고 우승 1대·작은 변이 탐색을 유지한다. 설정에서 자동 확대를 끌 수 있다. 화면에는 실제 구성·예정 구성·관절 토크를 표시한다. JSON v6는 자동 확대 설정·변이 프로필·시간 주파수와 541유전자를 저장한다. v1~v5는 원본을 유지하며 거절한다.

10세대쯤 15초 끝까지 버티기, 50세대쯤 유효 전진 보행을 실험 목표로 삼는다. 2초 지지 후 넘어지는 행동은 첫 목표 달성이 아니다. balance는 평가 끝까지 timeout+연속 지지 기준을 요구하고 전진 정체로 종료하지 않는다. 목표 세대에 도달했다고 성능을 합성하지 않는다.

0.9 새 실험은 지지 지속 보상(supported-curriculum-v5)을 사용한다. 발 단계는 지지를 평가 시간 전체에서 보상하고 발·접지 전진 보상에 실제 지지 비율을 곱하며 넘어짐350점을 감점한다. 서 있는 개체를7초에 정체 종료하지 않는다. 이전 저장은 이전 보상/종료를 보존하고 새 실험 적용으로만 개선 기준을 사용한다. 보상 수정 자체를 실제 네 발 보행 성공으로 표시하지 않는다.

# Walking Simulator 구조 (0.15.0)

2026-11-08. 실제 물리 기반 유전학습을 사용한다. 현재 앱은 기본44개 공통 제어기·선택38개·이전541/565/589개 순환망을 함께 지원한다. 학습된 네 발 전진 정책은 아직 검증되지 않았다. 과거 버전 실험·조정은 `VALIDATION_ADAPTIVE.md`에 남긴다.

## 물리와 제어

좌표는 x 전진·y 위·z 왼쪽, SI 단위다. Rapier3D0.21.0은 몸통1개와 네 다리의 어깨 링크·허벅지·종아리12개, 총13강체·12회전관절을 계산한다. 발은 종아리 collider이며 각 개체는 독립 World를 사용한다. 교체/종료 시 World를 해제하고 일시정지는 보존한다. 자기 충돌은 비활성화되어 있다.

고정dt=1/120초, solver12회·내부PGS4회다. 직접 신경망 출력[-1,1]×모터한도(기본18N·m)를 실제 관절 축의 토크로 적용한다. 자식과 부모에 크기가 같고 방향이 반대인 토크를 준다. 관절 속도가 설정8rad/s 이상이면 더 가속하는 구동 토크를 차단한다. 속도를 직접 덮어쓰지 않는다.

어깨[-0.7,0.7]rad·엉덩이[-1.6,1.1]rad·무릎[0.12,2.7]rad다. ForceBased 속도 모터의 목표속도0·감쇠1N·m·s/rad는 수동 점성 감쇠를 근사한다. 목표 관절각·몸통 위치 보정·외부 전진 힘은 없다. 공통 조립 자세는 다리마다[0,-0.6,1.2]rad, 발은 바닥 바로 위다. 이후 물리와 신경망만 구동한다.

표시 에너지는 구동 토크×관절 속도의 절댓값 적분이다. 전력 소비나 수동 감쇠의 손실 합계가 아니며, 관절이 끝에 고정되면 이 값이 작아질 수 있다. 따라서 새 보상에서는 끝단 토크를 별도로 평가한다.

## 신경망과 유전자

| 범위    | 역할                                    | 개수 |
| ------- | --------------------------------------- | ---- |
| 0–431   | 8개 뉴런의 입력44·기억8·편향1·시간상수1 | 432  |
| 432–539 | 12출력의 은닉 연결8·편향1               | 108  |
| 540     | 시간 주파수                             | 1    |
| 541–564 | 각 관절 자신의 정규화 각도·속도 연결    | 24   |
| 565–588 | 모터별 직접 sin/cos 시간 연결           | 24   |

기존 `timed-rnn-42+2x8x12-v3`는541개, `timed-rnn-proprio-565-v4`는565개, 기존 `timed-rnn-proprio-periodic-589-v5`는589개다. config.controllerModel과 체크포인트의 controllerVersion·유전자 길이가 일치해야 한다. `GENE_COUNT`는 기존541개 상수이며 새 길이는 `PROPRIO_GENE_COUNT`/`PERIODIC_GENE_COUNT`/`geneCount(config)`로 선택한다. 구파일을 조용히 패딩하지 않는다.

입력은 관절 각도12·속도12, 몸통 좌표의 위 방향3·각속도3·선속도3, 발 접촉4·바닥 이격4, 몸통 높이1로 총42센서다. sin/cos 시간 입력2개를 더한다. 위상은 `2π*((elapsed*frequency)%1)`이며 주파수도 난수 유전자다. 초기0.3~1.5Hz·허용0.15~3Hz다. 다리별 위상표·발 궤적은 없다.

센서와 기억 가중합은 각각sqrt(42),sqrt(8)로 정규화하고 시간 입력은 직접 합산한다. tanh 활성은 즉시 출력으로 전달한다. 기억은 `alpha=1-exp(-dt/tau)`로 갱신해 다음 tick에 사용한다. 출력의 tanh 직전에565개 이상 구조는 자신의 각도·속도×각 연결값을 더하고589개는모터별sin/cos연결도더한다. 연결 부호가 고정된 PD 제어기가 아니다.

초기 분포는 기존 입력/기억±0.5·은닉 편향±0.2·시간상수0.02~0.2초·출력 연결±0.25·출력 편향±0.1, 새 각도 연결±1·속도 연결±0.15·직접시간연결±0.01이다. 모두 시드 난수다. 진화의 연결 범위는±2, 시간상수0.02~1.5초다. 0연결에서는 시간 입력이 있어도 토크0이다.

기본 초기화는random이다. weak-balance는 조립 자세의 정적 하중 추정에 따라12개 출력 편향 중심만 이동하며 토크 비율 중심은±15%로 제한한다. 새 구조에서는 강도×자신의 각도 연결×정규화 조립 각도를 출력 편향에서 빼 초기 기여도 조건화한다. 강도1에서 첫 토크 분포는 기존 신호를 보존한다. 이것은 출생 유전자 변경이며 런타임 목표나 보정 힘이 아니다. 부모에는 매 세대 다시 주입하지 않는다.

## 걸음·지지·전진의 판정

FootCycle은 정상 지지에서 시작해35mm이상 발을 들고70ms이상 공중에 둔 뒤 세계+x로18mm이상 옮겨 착지해야 실제 한 걸음으로 센다. 초기 낙하·전신 점프·끌림·부적격 유각은 제외한다. 작은 중간 사이클도 들기/전진/체공의 정규화 곱을 사용하고 착지 후0.15초 정상 지지가 확인되어야 적립한다. 부분 진행은 실제 걸음으로 세지 않는다.

보행 gate는 몸통 높이≥0.24m·상한 이하, 기울기<0.5rad, 발2개이상 접지, slip<0.3m/s, 수직속도≤0.5m/s, 몸통/다리 끌림 없음, 점프 아님, 네 발 모두 최근3초 안 착지 이력이다. 이 gate와 전진속도>0.03m/s를 만족한 시간만 walkingTime으로 적립한다. 품질 시간은 높이·기울기·방향·미끄러짐·수직속도로 가중한다. 거리도 인정된 새 전진 구간만 증가한다. 전체최고x·접지전진 보조값은 별도다.

단계는balance→stepping→forward다. 앞 두 단계는3세대 연속 통과한 뒤 pendingStage를 다음 세대에 적용한다.

- balance: 평가 끝까지timeout, 연속 정상 지지2초, 새 기본은 연속 가동여유 지지2초·전체시간80%가동여유지지·종료jointFreedom≥.8도 요구한다. 새 키 누락은0으로 읽어 구 기준을 보존한다.
- stepping: 정상 지지2초·네발각2걸음(총8)·접지전진0.05m·연속보행1초·15초timeout·종료때walking gate다.
- forward: 거리1m·보행총10초·각발2걸음·새기준연속전진5초·판정때walking gate, 체공·최대코스이탈0.2m·최대방향이탈0.35rad 기준이다. useDriftLimits누락은false로읽어과거누적이동기준을보존한다. 짧은walking공백0.1초는연속구간만연결하고적립시간에는더하지않는다. 점프는즉시연속구간을끊는다.

최종 후보는 기준 및±0.035rad roll/±0.02rad pitch 두 초기 기울기, 총3조건에서 동일 유전자로 다시 평가한다. 세 조건 모두 실제로 통과해야 성공과 자동정지를 표시한다. 한 발 반복·세 발 이동·서 있기만으로 통과하지 않는다.

## 보상과 관절 가동 여유

현재 reward는mobile-curriculum-v8다. 이전 temporal-v4·supported-v5·cycle-v6·rhythmic-v7은 당시 점수/종료 규칙으로 재개한다. 누락 rewardModel은v4다. 평가 코드가 토크나 자세를 바꾸지 않는다.

표시점수는 내부점수×1000이다. support/steps/forward/continuity의 비중은balance=[.98,.01,.01,0], stepping=[.2,.6,.1,.1], forward=[.03,.12,.45,.4]다. 넘어짐은발/전진에서350점, 누적후진은전단계150점/m이며 왕복으로 취소되지 않는다. 체공·수직충격·옆이동·회전·에너지도 감점한다. 발단계는정체로7초종료하지 않는다.

v8은 각 관절의 끝단까지 여유를 가동범위15%로 정규화해 평균 jointFreedom을 계산한다. 범위끝2%를 벗어난 관절이9개 이상이고 정상지지·몸통높이≥minHeight+.15*(upper+lower)이면 가동여유지지로 센다. balance의지지항은 `.98*(.8*mobilityTime+.2*balanceTime)/duration`이다. mobilityTime은 정상지지 중 높이품질×jointFreedom의 적분이다.

끝2%에서 바깥쪽을 미는 토크가 저속0.15rad/s미만으로0.15초지속될 때 모터한도 대비 토크의12관절평균을 시간 적분한다. 이를 평가시간의10%로 정규화해 최대800점 감점한다. 관절이 움직이지 않아 기계적 일이0이어도 보상 허점을 만들지 않는다.

발 단계는 정상지지/평가시간 비율로 발·전진 보상을 가중한다. 첫/둘째 걸음 발견값과 최근3초 반복 활동을 함께 평가해 초반만 움직이고 멈추는 동작의 가점을 줄인다. 발별 중간연습은실제2걸음전까지만 반영한다. 체중이동은13강체의 실제 질량중심이 나머지3접촉발 삼각형 안에 있는 여유를 사용한다. 안쪽0.15초연속정상지지 후 준비도를시간적분해 발당2초에서포화한다. 체중이동/부분사이클은 최종 보행 조건을 대신하지 않는다.

## 유전 탐색과 계보 보존

새 기본 searchMethod=covariance는 자동 균형 단계에서36차원 분포를 학습한다. 좌표는12개 초기출력기여 `(bias+angleGain*assemblyAngle)/4`와24개 감각연결 `/4`다. 초기 좌표 표준편차는출력.0025·각도연결.05·속도연결.01이다. 변이폭/.03×sqrt(변이율/.1)을 강도로반영하고 설정변경도다음세대분포에적용한다.

우승1대와 별도로 실제균형통과개체가있으면추가1대까지정확히복사하고나머지를실제평가한다. Gaussian표본은거울쌍으로뽑고 유전자범위에서는평균으로부터복구한다. 새표본상위최대5부모를양의로그가중으로재조합하고 평균·공분산·진화경로를갱신한다. 이전우승은분포부모에서제외해분산축소를줄인다. 유효부모가부족하면점프부모로채우지않고실제최고개체에서분포를다시시작한다. 수학참고는[Hansen의CMA-ES설명](https://arxiv.org/abs/1604.00772),구현은독립작성했다.

수동결정·교차율>0·변이율0/100·adaptiveSearch=false·보행단계는일반GA를사용한다. 자동공분산도실제유전알고리즘이며 완성정책을초기집단에넣지않는다. 일반565개교차는의미가같은감각연결만이식하고출생편향을조건화한다. 변형시의도적으로변이된출력편향을상쇄하지않는다. 기존541개는원래RNG경로를유지한다.

589개 발/전진은작은/중간/큰변이폭기본.1/1.5/8%다. 정체전에도혼합비율55/25/15/5%로작은변이·중간·큰변이·새표본을섞으며실제개체수로반올림한다. 큰변이는일부자식에서한발의6시간연결을집중탐색한다. 출생시각도감각/시간cos기여변화를출력편향에조건화하고의도한편향변이는보존한다. 구565개는v14의폭을유지한다. 작은변이·물리관절묶음·센서열·출력망·미사용발탐색을섞는다. 0%/100%·수동부모를존중한다.

점수우승은항상1대보존한다. 개선된실제새발/부분사이클explorer를최대1대보존한다. 새v8에서는균형통과한별도계보stage-anchor도유지한다. 승급다음세대부터보행변이폭을사용한다. 작은변이자리를대체하며개체수는고정이다. 수동부모에없으면보존하지않고그자리를일반변이로돌린다. 세대의birth에는부모·원본유전자·실제변경좌표를기록하고재조합에는실제부모유전자·좌표·가중치도기록한다.

## 공통 관절 규칙과 방향 감각 (0.14.0)

`controllers/shared.ts`는 38개/44개 모형의 별도 유전자 이름·범위·직접 토크 계산을 정의한다. 공통 관절 3종×9연결(편향·자신의 각도/속도·몸통 위 방향 x/z·각속도 x/z·sin/cos)=27개, 자유 다리 위상4개·주파수1개, 학습하는 yaw 속도/좌우 속도 연결6개로 38개다. 시간 입력은 공통 `1-exp(-t/0.35)` 진폭으로 시작한다. 다리별 위상은 모두 자유 난수이며 앞뒤·좌우 관절 위치는 감각 특성에만 사용한다. 발 순서·고정 보정 게인·목표 자세·경로는 없다.

44개는 세계+x에 대한 몸통 방향 오차 `atan2(forward.z,forward.x)/π`, 좌우 위치 `clamp(z/0.5,-1,1)` 두 관측값과 관절종별 연결6개를 더한다. 이 모형만 센서 길이44를 사용한다. 기존 세 순환망과38개는42센서 그대로다. 0연결일 때 임의 방향/위치에도 능동 토크0이다. 실제38개 연구 개체의 평지 재생이 정확히 같았고,38→44 중립0연결은3초기 자세의 전체 물리 frame/점수를 보존했다.

## 해부학 좌표와 발 지지 판정 (2026-11-08 추가)

## 실제 접촉 하중 (0.15.0)

새 `evaluation.contactModel=load-bearing`은 Rapier의 발-바닥 manifold에서 정상 충격량을 읽는다. 각 발의 충격량이 `전체 질량 × |중력| × dt × 0.05`보다 커야 몸을 받치는 발로 센다. 구형 발의 바닥 재질점 `center-(0,radius,0)`에서 속도를 측정하고 각 발의 정상 충격량으로 평균해 접지 미끄러짐을 구한다. 영 하중의 예측 접촉점은 지지나 미끄러짐에 기여하지 않는다. 실제 하중이 실린 발의 끌림은 여전히 거절하고 정상 자세·두 발 지지·실제35mm 발 들기와 반복 착지를 유지한다.

`footSupport`는 이 측정만 계산하며 몸이나 토크를 수정하지 않는다. 하중 기준은 접촉 센서에도 쓰이므로 새 RNN 실험의 물리 반응은 달라질 수 있다. 이전 파일의 키 누락은 `proximity`로 복원해 원래 근접 접촉/발 중심 평균 경로를 그대로 사용한다. 새 실험 적용만 새 기준으로 바꾸고 과거 이력은 재점수 매기지 않는다. 하중 모형 파일은 앱0.15.0을 요구한다. 보상 함수 이름v8과 공통 탐색v3는 유지하되 접촉 모형·앱 버전을 함께 기록해 실험을 구분한다.

실제 연구100세대의 세 개체×세 자세 재평가에서 동일44개 정책의 몸·각도·토크를 모든tick 비교해 정확히 같았고 평가 통계만 달라졌다. 예를 들어 id16의 평지는 기존 연속0.633초에서 새 측정11.4초였지만 옆1.206m이탈·한 기울기 넘어짐이 남아 최종 실패다. 이것을 새 무작위 학습 성과라고 부르지 않는다.

이전 파일에서 새 실험을 시작할 때도 curriculum 전체를 현재 기준으로 적용한다. 이전 파일 복원 자체는 그대로이며, 사용자 조정 모형·물리값·평가시간은 유지한다.

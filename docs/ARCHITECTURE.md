# 물리·제어·진화 설계

제안 스택은 React, TypeScript, Vite, Canvas 2D, Planck.js, Web Worker, Vitest, Playwright다. 패키지 설치 시 호환되는 안정 버전을 확인하고 lockfile로 고정한다. 이 문서의 수치는 조정 가능한 초기 제안이다.

## 모듈과 데이터 흐름

src/app은 상태와 설정, components는 한국어 조작 UI, physics는 World와 접촉 판정, robot은 체형, controllers는 CPG, genetics는 PRNG와 진화, simulation은 평가·랭킹·상태 머신, visualization은 Canvas·선택·고스트, persistence는 검증·JSON·CSV, workers는 메시지와 계산 루프, tests는 검증을 담당한다. 아직 해당 폴더나 소스 코드는 생성하지 않았다.

UI 명령 → Worker의 명령 큐 → 고정 tick 물리 계산 → 종료·집계·진화 → 읽기 전용 화면 스냅샷 → Canvas. React 상태에 매 물리 프레임의 개별 강체를 넣지 않는다. DOM 좌표와 물리 좌표를 명시적으로 변환한다.

## 로봇과 World

각 개체마다 별도 World와 동일한 정적 지면을 만든다. 시작 tick은 전부 0이며 매 라운드에서 활성 개체 전부를 1 tick씩 계산한다. 각자 완료되면 그 World의 step을 중지하여 마지막 자세를 유지한다.

몸통 1 + 허벅지 4 + 종아리 4 = 동적 강체 9개, 회전 관절 8개. 발은 종아리에 부착한 원형 fixture로 구현해 불필요한 추가 관절을 줄인다. 제안 체형: 몸통 0.60×0.18m, 상·하 다리 각각 0.22m, 발 반경 0.035m. 몸통 4kg, 상다리 각각 0.35kg, 하다리·발 각각 0.25kg으로 목표 질량을 설정하고 fixture 밀도로 맞춘다. 기본 중력은 -9.81m/s², 지면 마찰 0.8, 반발계수 0.0을 제안한다.

앞 2다리와 뒤 2다리는 같은 투영 위치에서 독립 관절로 연결한다. 동일 로봇의 self collision은 초기에는 비활성화하고 몸통·발·다리와 지면은 충돌시킨다. 투영된 다리끼리 얽히는 인공적 장애를 방지하되 3D 충돌 재현으로 주장하지 않는다. 초기 자세는 두 무릎이 유효 범위 안에서 굽혀지고 발이 지면을 관통하지 않도록 기하로 계산한다.

각 관절은 enableLimit/enableMotor와 유한 maxMotorTorque를 사용한다. 초기 엉덩이 상대각 한계 [-0.9,0.9]rad, 무릎 [0.05,1.7]rad, 토크 한도 엉덩이 12N·m·무릎 9N·m, 속도 한도 8rad/s를 제안한다. 무릎 굽힘 방향은 관절 로컬 좌표의 부호로 통일한다. referenceAngle·초기 상대각과 제어 목표의 정의를 테스트에서 일치시킨다.

## CPG 유전자: 27개 실수

| 변수 | 개수 | 초기 탐색 범위 |
| --- | --- | --- |
| 주파수 f | 1 | 0.4–2.5Hz |
| 앞·뒤 위상차 δfrontRear | 1 | -π–π |
| 좌·우 위상차 δleftRight | 1 | -π–π |
| 다리별 엉덩이 기본각 bH | 4 | -0.35–0.35rad |
| 다리별 엉덩이 진폭 aH | 4 | 0–0.55rad |
| 다리별 무릎 기본각 bK | 4 | 0.45–1.15rad |
| 다리별 무릎 진폭 aK | 4 | 0–0.45rad |
| 다리별 무릎 위상 ψ | 4 | -π–π |
| 다리별 잔여 위상 ε | 4 | -0.3–0.3rad |

각 다리 위상 φ는 위치(앞/뒤, 좌/우)에 따른 두 위상차와 잔여 위상을 더한다. θH*=bH+aH sin(2πft+φ), θK*=bK+aK sin(2πft+φ+ψ). 목표는 관절 제한 안쪽으로 clamp한다. 초기 0.5초 동안 진폭을 부드럽게 올려 초기 충격을 줄이며 모든 개체에 동일하게 적용한다.

모터 목표 속도는 clamp(kp(θ*−θ)−kd·관절각속도, ±ωmax)로 계산한다. Planck 회전 모터가 토크 한도 내에서 속도를 추종한다. 직접 각도·위치·수평 속도를 덮어쓰거나 전진 힘을 별도로 주지 않는다. 초기 kp=8/s, kd=0.3을 제안하며 모든 개체에 공통 적용한다. 모터가 한 일은 Σ|실제 motorTorque × jointSpeed|dt로 누적한다. 이 값은 물리적 기계 일의 근사이며 실제 배터리 소비량이 아니다.

## 고정 스텝과 고속 계산

초기 dt=1/120초, 속도 반복 8회·위치 반복 3회를 제안한다. 평가 시간은 초 대신 tick으로 변환하여 종료한다. 렌더 30/60FPS와 배속 변경은 step 크기를 바꾸지 않는다. 시간은 Date.now 대신 tick×dt다.

Worker 한 개가 모든 World를 소유한다. 약 4–8ms의 계산 묶음 후 이벤트 루프에 제어를 반환하고 명령을 처리한다. 10–20Hz로 최신 화면 스냅샷을 전송한다. 완료 세대 이벤트는 누락하지 않고 별도로 전달한다. 스냅샷 전송 수를 제한해 오래된 화면이 큐에 쌓이지 않게 한다. 자동 진화 직전에도 정지 명령을 확인한다. UI는 정지 요청을 즉시 표시하고 Worker ack의 tick을 최종 정지 지점으로 삼는다.

배속 목표를 달성하지 못하면 실제 시뮬레이션 초/벽시계 초를 표시한다. 시간 스텝이나 평가를 생략해 수치를 맞추지 않는다. 동일 엔진·버전·환경·시드에서 재현성을 검증하고 서로 다른 브라우저의 부동소수점까지 비트 단위 동일하다고 보장하지 않는다.

## 평가와 편법 방지

유효 거리 D는 max(0, 유효하게 전진한 몸통 중심의 최고 x−출발 x)로 정의한다. 이전 유효 최고 거리에 도달한 최초 tick도 기록한다. 시작 발 자세, 물리 시드, 지면은 동일하다.

유효 tick 조건은 몸통-지면 접촉 없음, 기울기 |θ|≤1.0rad, 유한 수치·속도·관절 상태 정상, 정상 높이 범위이며 최근 0.2초 안에 발 접촉이 한 번 이상 있는 상태로 제안한다. 발 접촉 기준은 정상 보행의 짧은 공중 단계를 허용하기 위한 것이다. 비정상 높이 상한은 체형의 최대 기립 높이+0.15m로 제안하고 물리 테스트 후 조정한다.

몸통 접촉이 발생한 tick의 이동은 거리로 인정하지 않으며 즉시 넘어짐으로 종료한다. 기울기 이탈은 0.35초 연속일 때 넘어짐으로 종료하지만 이탈 중에는 거리 갱신을 멈춘다. 따라서 넘어지거나 구르는 도중 얻은 이동이 기록을 올리지 않는다. 종료 후의 위치·자세는 실제 상태 그대로 유지한다.

준비 2초 뒤 연속 3초간 유효 최고 거리 증가가 0.03m 미만이면 정체 종료한다. 15초 도달은 시간 종료, 유효 거리 목표 10m 도달은 성공이다. 모든 값은 실험 설정에 둔다. 여러 종료 조건이 겹치면 비정상→몸통 접촉/넘어짐→성공→시간→정체 순서로 판정한다. 예외는 해당 개체를 invalid로 기록하고 가능한 한 나머지 평가를 계속한다.

보조 적합도 예시 F=0.5U+0.3S−0.2E: U는 정상 자세 시간/평가 제한 시간, S는 정상 자세 구간의 평균 exp(−θ²), E는 W/(W+100J)다. 유효 구간이 없으면 S=0으로 정의한다. 거리와 F를 구분해 표시한다. 부모는 공식 거리 순위 기반으로 뽑아 에너지 점수가 거리 우선순위를 바꾸지 않게 한다. 굴림·끌림·점프·관통 사례로 유효 조건의 허점을 검증한다. 물리적으로 가능한 점프를 완전히 차단할 수 있다고 주장하지 않으며 기준 변경은 실험 버전을 바꾼다.

## 유전 알고리즘

시드를 지정할 수 있는 직렬화 가능한 정수 PRNG를 사용한다. 초기 유전자는 각 범위에서 무작위 추출하며 완성 보행을 주입하지 않는다. 초기 개체 수 20, 교차율 0.8, 유전자별 돌연변이 확률 0.10, 변이 표준편차는 범위의 0.08을 제안한다.

자동 부모 후보는 공식 순위 상위 max(2, ceil(N×0.25))개다. 후보에서 크기 3 토너먼트로 부모를 뽑는다. 수동 모드는 선택된 후보만 사용한다. 1등 유전자 하나를 깊은 복사하여 보존한 뒤 N−1개를 생성한다. 교차는 유전자별 균일 교차, 변이는 시드 기반 정규 잡음이다. 위상은 주기 범위로 wrap하고 다른 변수는 clamp한다. 교차하지 않을 때도 부모를 복사하며 참조 공유를 금지한다. 엘리트에는 교차·변이하지 않는다.

챔피언 보존이 실제 점수 개선을 보장하지 않는다. 같은 설정에서 동일 유전자 재평가 결과가 달라지면 물리·난수·초기화 오류부터 조사한다.

## 고스트·메모리·복원

각 개체의 실제 몸통 pose와 8개 관절각을 20Hz로 기록하고 최종 프레임을 추가한다. 매 프레임에는 simulationTick, 유효 거리도 담는다. 종료 시 최고 후보의 기록만 장기 유지한다. 역대 최고와 직전 최고를 선택할 수 있게 하고 무제한 궤적 보관을 피한다. 고스트는 현재 평가 시간에 맞춰 보간하며 기록 종료 후 마지막 자세를 유지한다. world 좌표에서 그리되 현재 레인 카메라를 사용한다. 재생 결과를 물리 입력·부모 후보로 사용하지 않는다.

중간 일시정지는 살아 있는 World를 그대로 보관한다. JSON으로 World의 위치·속도만 저장해 접촉 solver까지 완전히 복원할 수 있다고 가정하지 않는다. 초기 파일 복원은 완료 세대 경계에서 새 World를 생성해 다음 세대를 시작하는 방식이다.

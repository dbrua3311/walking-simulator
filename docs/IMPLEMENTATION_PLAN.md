# 구현 순서와 완료 기준

현재 완료한 범위는 요구 분석과 설계 문서 작성뿐이다. 아래는 사용자 코딩 시작 지시 이후의 계획이다.

| 단계 | 구현 | 다음 단계 진입 기준 |
| --- | --- | --- |
| 0 | 전용 Git 초기화·기능 브랜치, 저장 위치 검사, React/TS/Vite와 테스트 환경 | 기존 폴더 변경 없음, 모든 캐시 경로 확인, 빈 앱 빌드 |
| 1 | 단일 로봇 9강체·8관절·지면·접촉·기울기 종료 | 자유 낙하·관절 한계·발 마찰·유한 토크 검증 |
| 2 | 27개 유전자 CPG와 시드 PRNG | 직접 위치 이동 없음, 다른 유전자에서 다른 실제 궤적 |
| 3 | 유효 거리·종료·순위·교차·변이·엘리트 | 순위 반례·계보·원본 불변·엘리트 동일성 검증 |
| 4 | 20개 독립 World와 레인 Canvas | 전부 tick 0 시작, 독립성·종료 자세 고정 |
| 5 | 클릭·드래그·부모 확정 | 마지막 화면 유지, 결정완료 전 세대 불변 |
| 6 | Worker·고속·자동 진화·정지 ack | dt 일치, 실제 배속 측정, 반복 전환 시 상태 보존 |
| 7 | 금색 1개체·오라·실제 고스트·통계 | 장식이 평가 불변, 시간 동기와 그래프 보존 |
| 8 | 경계 JSON 저장·검증·복원·CSV | 손상 파일 시 현재 실험 불변, 시드 재개 일치 |
| 9 | 장기 실험·프로파일·회귀 검증 | 메모리 증가 원인 확인, 학습 결과와 실패 분석 보고 |

의존성을 설치하기 전에 Node/npm 유무와 버전·메인 디스크 잔여 공간을 검사한다. 필요한 도구 추가 설치도 외부 파티션에 배치한다. Playwright는 우선 Chromium 하나만 설치해 저장 용량을 줄인다. Docker, Python 가상환경, 모델 체크포인트는 필요하지 않다.

학습 실험은 먼저 임의 개체군 20개 × 10시드의 기준선을 측정하고, 이후 같은 10시드에서 100세대 진화 실험을 수행하는 안을 제안한다. 실행시간을 먼저 측정하고 가능한 범위에서 실험 규모를 기록해 조정한다. 세대별 최고·중앙값·평균·성공률·넘어짐·소요 시간과 역대 최고 유전자를 저장한다. 개선이 없다면 초기 접촉·모터 범위·종료 과민성·유효 거리 조건·유전자 다양성·조기 수렴을 구분해 조사한다. 결과를 본 뒤 시드나 실패 시행을 숨기지 않는다.

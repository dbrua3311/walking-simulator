# 구현 순서와 완료 기준

의존성을 설치하기 전에 Node/npm 유무와 버전·메인 디스크 잔여 공간을 검사한다. 필요한 도구 추가 설치도 외부 파티션에 배치한다. Playwright는 우선 Chromium 하나만 설치해 저장 용량을 줄인다. Docker, Python 가상환경, 모델 체크포인트는 필요하지 않다.

학습 실험은 먼저 임의 개체군 20개 × 10시드의 기준선을 측정하고, 이후 같은 10시드에서 100세대 진화 실험을 수행하는 안을 제안한다. 실행시간을 먼저 측정하고 가능한 범위에서 실험 규모를 기록해 조정한다. 세대별 최고·중앙값·평균·성공률·넘어짐·소요 시간과 역대 최고 유전자를 저장한다. 개선이 없다면 초기 접촉·모터 범위·종료 과민성·유효 거리 조건·유전자 다양성·조기 수렴을 구분해 조사한다. 결과를 본 뒤 시드나 실패 시행을 숨기지 않는다.

2026-11-07 추가 요청: 3D Rapier 13강체·12관절·Three.js 모델과 관찰 카메라, 16개 지지/유각 유전자, 끌기 방지 보행 인정 기준으로 교체했다. 기존 2D 검증 기록은 역사 자료이며 현재 무작위 학습 결과는 VALIDATION_RANDOM.md를 따른다.

2026-11-07 최종 제어 방향: 사전 발 경로·보행 위상·IK·자세 보정을 제거하고 무작위 신경망 직접 토크 제어로 교체했다. 첫 세대 즉시 보행 성공 기준을 제거하고 무작위 초기화·실제 토크·숨겨진 보행 부재·재현성·20대 선택과 변이를 검증한다.

## 자동 검증

Vitest **58개 통과**, TypeScript·프로덕션 빌드 통과. 검증 범위:

- 시드별 전체 유전자 무작위 생성, 42센서·8순환 뉴런·12토크와 524개 길이.
- 0가중치·편향에서 어떤 센서에도 출력 0. 관절별 편향이 해당 토크만 바꿈.
- 같은 유전자·센서열에서 같은 출력과 순환 기억. 실제 센서·이전 기억이 출력에 영향.
- 세 관절 축에 직접 토크를 출력해 실제 각도가 올바른 방향으로 변함.
- 관절 부모·자식의 토크 합이 0, 토크 한도, 중력·접촉·13강체·12관절.
- 0출력 정책은 자세를 유지해 주지 않고 중력으로 무너짐. 공통 조립 자세 뒤 무작위 유전자에 따라 실제 궤적이 달라짐.
- 유효 보행 조건과 끌기·낮은 몸통·높은 미끄러짐·지지 부족 거절.
- 20대 부모 복사, 최소 실제 변이, 변형 폭 한도, 엘리트·부모 원본 보존.
- 일시정지 중 World·순환 기억·난수 보존, 새 v3 파일과 다음 세대 재현.
- 이전 2D v1·사전 보행 v2를 거절하고 현재 실험 유지.

Chromium E2E **5개 시나리오 검증 완료**: 기본 화면·클릭/드래그·엘리트, 자동 정지·재개, JSON/CSV와 손상 파일, 모바일 20대 선택, 기본 20대와 부모 복사·19개 자식 변이·유전자 검사창 페이지다. 데스크톱에서 JSON 다운로드 버튼으로 스크롤한 뒤 화면 밖 칸을 클릭하던 테스트를 수정하고 해당 시나리오를 재실행해 통과했다. 제품의 선택 처리는 변경하지 않았다.

최종 측정에서 4대 자동 정지 조작부터 반영은 258ms, 20대는 333ms였다. 헤드리스 소프트웨어 WebGL·Playwright 동작을 포함한 측정이다. 기존 200ms 목표를 충족한 결과로 표현하지 않는다. 브라우저 회귀 한도 500ms를 통과했다. 화면은 USB의 `/mnt/piper-usb/walking-simulator/artifacts/population-20.png`와 `mobile.png`에 기록했다.

## 유지하는 공통 조건

신경망 구조·센서 정규화·물리·관절 한도·공통 조립 자세·보상 기준은 사람이 정의한다. 사전 보행 위상·발 경로·IK·균형 보정·완성 가중치는 없다. 이 버전은 로봇 정책의 진화 실험이며 인간 생체 보행·실물 로봇 검증 결과가 아니다. 관절 자기 충돌은 꺼져 있다. 주행 중 파일 체크포인트는 지원하지 않고 완료 세대 경계에서 저장한다.

## 회색 표시·생존 시간 선발 추가 검증

2026-11-07 요청에 따라 평가가 끝난 칸과 상세 화면에 25% 회색 덮개를 적용했다. 자동 부모·금색 엘리트·화면 순위는 종료 tick이 늦은 순서이며 동률은 적합도·보행 거리·ID 순이다. 전체 일시정지된 active 개체는 종료로 표시하지 않는다. 거리 통계와 거리 고스트는 별도 거리 순위를 유지한다.

단위 테스트 **61개 통과**, 타입 검사·빌드 통과. 기존 브라우저 5개와 새 회색·생존 선발 검증까지 **6개 시나리오 확인**했다. 새 검증에서 일부 개체만 회색으로 전환되는 구간, 종료 상세 화면, 실제 JSON 종료 시간순 상위 2개와 자동 부모 ID 일치, 선택만으로 세대가 넘어가지 않음을 확인했다. 자동 선택 결과를 읽을 때 Worker 응답 반영을 기다리도록 테스트를 보완한 뒤 해당 검증을 재실행했다.

최종 기존 회귀 실행의 자동 정지 반영은 4대 188ms·20대 221ms였다. 원래 200ms 목표를 매번 만족했다고 표현하지 않는다. 기존 20세대 raw v3 파일(selectionVersion 없음)의 파싱도 성공했다. 새 파일은 selectionVersion=survival-v1을 기록한다. 위 과거 20세대 수치는 새 선발 규칙의 개선 실험으로 재해석하지 않는다.

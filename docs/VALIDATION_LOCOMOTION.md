# 공중점프 평가 수정 검증 — 0.4.0

2026-11-07, Asia/Seoul. 사용자가 보고한 주된 실패 행동은 공중점프였다. 무작위 신경망과 유전 알고리즘을 유지하며 평가·선발·구동 안정성·탐색 방식을 수정했다. 이 문서의 실험은 실제 Rapier 계산이다. 보행 성공 결과를 합성하거나 성공 유전자를 초기 세대에 주입하지 않았다.

## 원인과 변경

이전 survival-v1은 종료 tick을 우선 비교했다. 따라서 공중에 머무르는 시간이 걸음보다 유리할 수 있었다. 발 사이클도 전체 로봇이 점프했는지 구분하지 않아 초기 낙하·점프 착지를 발 옮김으로 셀 수 있었다. 체공·수직 운동 벌점도 없었다.

현재 walking-v1은 보행 점수를 우선한다. 접촉 없는 수평 이동에는 전진 점수를 주지 않고 체공·제곱 수직 속도·옆 이동·회전·에너지를 감점한다. 연속 전신 체공 0.12초 초과나 높이 상한 초과는 점프 종료다. 초기 낙하와 전체 점프 착지는 걸음에서 제외한다. jumped/invalid는 유효 후보가 있으면 자동 부모에서 제외한다. 회색은 평가 종료 표시로 유지한다.

초기 신경망은 작은 대칭 난수로 만들며 센서의 현재 활성과 느린 기억 경로를 분리했다. 관절에는 수동 점성 감쇠를 추가했다. 각도 목표·보행 궤적·IK·자세 복원 제어는 없다. 0출력 로봇이 중력으로 무너지는 회귀 검사를 유지한다. 일부 자식에 한 관절 출력의 국소 변이를 적용하고 보행 거리 10세대 정체 시 10% 새 무작위 개체를 탐색한다.

수직 속도 벌점 설계는 공개 구현의 개념을 참고했다. [legged_gym의 보상 구현](https://github.com/leggedrobotics/legged_gym/blob/master/legged_gym/envs/base/legged_robot.py)은 수직 속도 제곱 항 등을 포함한다. 이 프로젝트는 해당 환경이나 학습 정책을 가져오지 않으며 자체 유전 알고리즘·물리·평가를 사용한다.

## 자동 회귀 검사

- Vitest 72개 통과: 기존 물리·무작위 신경망·유전·정지/복원과 새 점프 평가·착지 제외·선발·탐색 개체 검증.
- 실제 강체 13개 모두에 위쪽 속도를 준 검사에서 jumped 종료, 걸음 0/0/0/0, 보행 거리 0, 음수 점수를 확인했다. 이 속도 주입은 테스트에만 있다.
- 합성 관찰열에서 정상 접지 전진·발 옮김이 서 있기·점프·옆 이동보다 높은 점수를 얻고 제자리 왕복이 전진을 축적하지 않음을 확인했다. 이 검사는 평가식 반례 검증이며 신경망이 실제로 그 보행을 학습했다는 증거가 아니다.
- TypeScript 검사·Vite 빌드 통과. 큰 Rapier/Three 번들 경고는 남아 있으며 실행 실패는 아니다.
- Playwright 실제 Chromium 6개 통과(최종 약 1.2분): 20대 표시, 선택/변이/엘리트, 자동 정지·재개, JSON/CSV·복원·손상 거절, 좁은 화면, 일부만 종료된 회색 상태·보행 점수 자동 부모와 상세 종료 효과.
- 실제 클릭 이벤트→일시정지 DOM 표시 측정은 4대 121.2ms·20대 209.6ms였다. 정지 후 tick·지표·자세 보존을 검사했다. 200ms 목표를 모든 조건에서 달성했다고 표현하지 않는다. 이전 자동화 측정은 클릭 전 스크롤·동작 가능 대기까지 포함해 병행 부하에서 2779ms가 나온 적이 있어 실제 입력 구간과 구분했다. Worker ack 자체만 잰 수치는 아니다.
- 회색 중간 상태는 클릭 전에 DOM 관찰을 설치하고 20대에서 검사한다. 4대의 짧은 종료 간격은 검사 재개 전에 지나가거나 같은 화면 갱신에 합쳐질 수 있어 비결정적이었다. 최종 검사는 일부 종료 상태와 전체 종료 상태를 모두 관찰했다.
- 화면: `/mnt/piper-usb/walking-simulator/artifacts/gray-walking.png`, `/mnt/piper-usb/walking-simulator/artifacts/population-20.png`. 실제 100세대 JSON 세 파일도 현재 v4 파서로 검증했다.

## 실제 무작위 진화 100세대

조건: 개체 20, 세대당 최대 15초, dt=1/120, 기본 설정, 자동 상위 5부모, 우승 1 보존, 변이 10%·폭 3%, 교차 0%, 관절 감쇠 1. 각 시드마다 새로운 난수 초기 세대에서 시작해 100세대(2,000개체 평가)를 계산했다.

| 시드 | 최고 점수 처음→마지막 | 세대 내 최대 안정 지지 시간 처음→마지막 | 마지막 우승의 접지 전진 | 인정 보행 거리 | 우승 걸음 |
| ---- | --------------------- | --------------------------------------- | ----------------------- | -------------- | --------- |
| 2026 | 0.019748→0.125437     | 0.475→2.025초                           | 0.196710m               | 0m             | 0/0/0/0   |
| 2027 | 0.021426→0.107991     | 0.491667→1.983333초                     | 0.111454m               | 0m             | 0/0/0/0   |
| 2028 | 0.018720→0.183352     | 0.608333→2.183333초                     | 0.219519m               | 0m             | 1/0/0/0   |

각 시드의 처음/마지막 세대 점프 개체와 마지막 우승의 체공은 0이었다. 처음부터 점프가 없었으므로 이 수치로 점프 빈도 감소를 주장하지 않는다. 평가의 점프 편법 차단은 위 회귀 검사로 확인했다.

**아직 실제 걷기는 발견하지 못했다.** 점수와 안정 지지는 개선됐지만 접지 전진은 공식 보행 거리와 다른 보조 지표다. 발을 지면에서 옮기지 않는 지지 상태 전진·기울어짐도 포함할 수 있다. 시드 2028에서 30세대부터 한 발의 실제 들기·앞 이동·착지가 기록됐지만 네 발 교대와 연속 보행은 발견하지 못했다. 세 시드 전체 6,000회 평가에서 invalid는 0회였다. 점수 상한·초기 균형 보상만으로 장기 수렴이 보장되지 않는다.

이전 버전과는 초기 난수 분포·신경망 응답·물리 감쇠·변이도 달라졌다. 이 실험으로 개별 변경 하나의 효과를 분리하지 않는다. 긴 학습의 수렴이나 다른 시드의 성능도 보장하지 않는다.

## 다음 개선 제안: 연속 전진 보행

사용자의 최종 목표는 앞으로 안정적으로 걷는 로봇을 무작위 유전학습으로 얻는 것이다. 아래는 후속 설계 제안이며 현재 구현했다고 표현하지 않는다.

- 무작위 시작·20대 동시 관찰·부모 복사/변이를 유지한다. 보행 위상·다리 순서·관절 각도 궤적은 넣지 않는다.
- 첫 단계는 짧은 균형 유지, 다음은 지지하면서 여러 발 옮김, 마지막은 지속 전진으로 평가 비중을 옮기는 자동 학습 단계를 검토한다. 예시 전환 기준인 안정 지지 2초는 아직 확정·검증된 값이 아니다. 서 있기만 하는 보상은 이후 단계에서 줄인다.
- 동작 다양성을 보존해 한 발 동작이나 한 계보만 남지 않도록 한다. 점프·끌기와 다른 유효 동작을 구분하고, 보행 점수만 높은 한 계열과 새로운 발 사용 계열을 함께 탐색하는 방안을 비교한다.
- 최종 판정은 여러 발의 반복 착지, 실제 전진 거리, 넘어짐·장기 체공·미끄러짐, 옆 이탈·몸통 흔들림을 함께 본다. 예시 목표는 10초 동안 1m 이상 안정 전진이며 합격 기준으로 확정하기 전 실제 실험으로 조정한다.
- 우승 개체는 약간 다른 초기 자세에서도 재평가해 반복 가능한 전진을 확인한다. 학습 단계·평가 버전을 저장하고 다른 단계의 점수를 같은 그래프에서 직접 비교하지 않는다.

단계별 난이도 조정은 [사족보행 학습 연구](https://arxiv.org/abs/2109.11978)에서도 사용된다. 이 연구는 대규모 병렬 강화학습이므로 현재 20대 GA에 그대로 적용한 성능 증거는 아니다. [진화 탐색의 목적 함수와 다양성에 관한 연구](https://www.cs.swarthmore.edu/~meeden/DevelopmentalRobotics/lehmanNoveltySearch11.pdf)는 점수 개선이 최종 목표에 접근한다는 보장이 없음을 다룬다. 위 조합은 현재 실패 관찰에서 도출한 후속 실험 제안이다. 단순히 세대 수를 늘려 수렴을 가정하지 않고 여러 시드의 실제 연속 보행으로 검증한다.

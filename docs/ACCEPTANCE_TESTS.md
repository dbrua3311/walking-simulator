# 검증 기준

아래는 검증 계획과 판정 기준이다. 실행한 항목의 실제 결과는 VALIDATION_CURRICULUM.md에 별도 기록한다. 잠정 수치 허용 오차는 물리 단계에서 확정하고 이후 임의로 완화하지 않는다.

## 물리와 평가

- 모터를 끈 단일 강체 자유 낙하를 충돌 전 해석값과 비교한다. dt 1/120에서 0.5초 위치 오차 0.03m 이내를 초기 기준으로 둔다.
- 4개 다리·12개 구동 관절을 확인하고 실제 각도·토크를 수집한다. 제한 각도 초과는 0.05rad 이하, 토크는 설정 한도+수치 허용 오차 이내인지 확인한다.
- 지면 접촉 후 발 관통은 0.02m 이내를 초기 기준으로 한다. 수동 수평 속도를 준 테스트 강체에서 마찰 0과 0.8의 감속을 비교한다.
- 몸통 접촉, 지속 기울기, 정체, 시간, 목표, NaN/Infinity 종료를 각각 유발한다. 짧은 기울기 이탈은 종료하지 않으며 이탈 구간 거리도 추가하지 않는다.
- 구르기·몸통 끌기·착지 충격·지면 관통·과도한 점프를 테스트하여 유효 거리 부당 증가가 없는지 확인한다. 수동 상태 주입은 테스트 전용이며 제품 학습에 사용하지 않는다.
- 종료 후 다른 개체를 1000tick 진행해도 종료된 개체의 pose·속도·거리 기록이 달라지지 않는다.

## 독립성·재현성·진화

- 같은 유전자·설정·시드의 1개체 단독 실행과 20개체 속 실행 결과를 비교한다.
- 화면 30/60FPS, 1배속/고속, 화면 렌더 없음에서 동일 tick 결과를 비교한다. 같은 실행 환경에서 거리 차이 1e-8m 이내를 초기 목표로 한다.
- 유전자 2종이 실제 관절 궤적을 바꾸는지 확인한다. 교차율 1에서 두 부모의 유전자 출처, 변이율 1에서 범위·변화를 검증한다.
- 부모 원본과 엘리트가 자식 변이에 영향받지 않는다. 다음 세대 챔피언 유전자는 이전 1등과 모든 값이 정확히 같다.
- 선발은 jumped/invalid 뒤로, 보행 점수·보행 거리·접지 전진·안정 지지 시간·ID 순이다. 거리 통계용 정렬은 거리 구간·보행 점수·도달 tick·ID 순으로 별도 검증한다.
- 첫 세대 champion 수는 0, 이후 세대는 정확히 1이다.

## 화면과 자동 정지

- selection에서 실제 마지막 위치·자세가 유지된다. 클릭 재선택 해제, 스크롤·확대·DPR 변환, 드래그와 겹침 선택을 검증한다.
- 선택만 해서는 세대가 늘지 않으며 결정완료 후에만 늘어난다. 부모 0개 확정은 차단한다.
- 자동 학습이 여러 세대의 실제 물리를 계산하고 통계를 빠짐없이 보낸다. 정지 후 같은 화면에서 일반 실행·자동 시작을 반복한다.
- 기준 PC에서 정지 버튼 입력부터 Worker ack까지 200ms 이내를 목표로 측정한다. 정지 ack tick 이후 재개 전까지 평가 시간·World·유전자·난수 상태가 바뀌지 않는다.
- 정지와 세대 경계가 겹치는 경우 명령 적용 순서와 ack 세대를 기록하고 중복 진화가 없는지 확인한다.
- 고스트·오라를 켠 결과와 끈 결과가 동일하다. 고스트가 실제 기록의 같은 tick 위치를 따라가며 선택되지 않는다.

## 저장과 자원

- 완료 세대를 저장→불러오기→같은 부모 확정하여 다음 세대 유전자·난수 상태·결과가 연속 실행과 일치하는지 확인한다.
- 잘린 JSON, 잘못된 버전, 중복 ID, 초대형 배열, 비정상 수치·누락 필드를 거절하고 기존 실험은 보존한다.
- CSV 행 개수와 단위·최고 거리·독립적인 최고 보행 점수를 원본 통계와 대조한다.
- USB 제거·외부 마운트 누락·디스크 부족을 모의 검사하여 메인 디스크로 fallback하지 않는다.
- 100세대 실행에서 World가 세대마다 해제되고 궤적 보관이 설정된 상한을 넘지 않는다. 벽시계 성능과 실제 배속을 측정해 보고하며 임의 배속 성능을 주장하지 않는다.

## 3D 추가 검증

- 세 관절 축 각각 실제 토크 출력으로 올바른 방향으로 움직이는지 확인한다.
- 무작위 초기 세대의 보행 성공은 요구하지 않는다. 0출력 신경망에서 숨겨진 자세 보정 없이 중력으로 무너지는지 확인한다.
- 네 발 걸음 이력이 없거나, 낮은 몸통·높은 미끄러짐·다리 끌림·한 발 지지·오래된 착지 이력은 보행 거리로 인정하지 않는다.
- 3D 상세·전체 보기·회전 카메라·레이캐스트/드래그 선택·개체 수 변경·React/WebGL 정리를 검증한다.
- 이전 v1·v2·v3·v4는 거절하고 v5의 강체·신경망·계보·다음 세대 재현을 검증한다.

## 20대 관찰·부모 복사 추가 검증

- 기본 화면에 20개 관찰 칸과 20개 실제 3D 렌더 영역이 함께 표시된다. 모바일·데스크톱의 관찰 칸과 클릭 영역이 일치한다.
- 탐색이 발생하지 않는 세대에서 부모를 1개만 고르면 우승 보존 1대 이외 자식 19대의 부모가 모두 그 개체다. 클릭만으로는 진화하지 않는다.
- 양수 변이율에서 모든 자식이 실제로 최소 1개 유전자가 달라지고, 부모 대비 변화는 유전자 범위×변형 크기 이내다. 경계값에서도 변형되고 0%일 때 정확히 복사한다.
- 부모 여러 개를 선택하면 순위순으로 돌아가며 자식을 만든다. 원본 부모는 바뀌지 않는다.
- 실제 계보가 JSON 저장·복원 후 같고, 변경 인덱스 위조는 거절한다. 이전 16유전자 v2 파일은 거절한다.

## 무작위 신경망 추가 검증

- 42센서+2시간 입력·8순환 뉴런·12출력, 541개 무작위 유전자를 확인한다.
- 0가중치·편향에서는 어떤 센서에도 토크가 0이다. 관절 편향 하나를 바꾸면 해당 출력만 변한다.
- 센서와 이전 기억이 출력에 영향을 주고 같은 유전자·센서열은 같은 출력·기억을 만든다.
- 구동 토크는 부모·자식에 반대로 작용하며 전체 외부 구동 토크 합은 0이다.
- 같은 조립 자세에서 다른 신경망은 다른 실제 관절 운동을 만든다.
- 정지 시 순환 기억을 유지하고 파일 복원 후 다음 세대가 연속 실행과 같다.

## 회색·보행 선발

- 처음에는 회색 칸이 없고, 일부 개체 종료 시 해당 칸만 회색으로 바뀐다. 종료된 상세 화면에도 적용한다.
- 회색 칸을 클릭·드래그 선택할 수 있고, 살아 있는 개체의 전체 일시정지는 실패로 처리하지 않는다.
- 긴 체공이나 오래 서 있기보다 실제 지지하며 전진하고 발을 옮긴 개체가 높은 점수를 얻는다. jumped/invalid는 유효 자동 부모에서 제외한다.
- 자동 선택 상위 N개체와 보행 점수 1위 엘리트의 실제 부모 ID를 검증한다. 선택만으로 진화하지 않는다.
- 거리 통계·고스트의 의미는 유지한다. 이전 raw v3는 새 실험을 안내하며 거절하고 현재 메모리를 보존한다.

## 공중점프 회귀와 탐색

- 전신 비행의 수평 이동에 접지 전진 보상을 주지 않는다. 장기 체공·높이 상한 초과는 jumped로 종료한다.
- 네 발 동시 점프 착지와 초기 낙하를 네 걸음으로 세지 않는다. 정상 지지 후 발 들기·앞 이동·착지는 계속 센다.
- 수직 충격·높이·점프 상태를 보행 거리 gate가 차단한다. 제자리 왕복은 전진 보상을 축적하지 못한다.
- 실제 Rapier 로봇의 모든 강체에 위쪽 속도를 준 회귀 검사에서 점프 종료·걸음 0·거리 0을 확인한다. 상태 주입은 테스트에서만 수행한다.
- 센서 반응은 첫 tick에 전달하고 순환 기억도 유지한다. 0출력 신경망은 수동 감쇠가 있어도 자세를 지키지 못한다.
- 정체 이후 탐색 개체 수·무작위 생성·부모 없음·champion 아님을 확인한다. 나머지 자식의 부모 기여와 최소 변이는 유지한다.
- v5 파일의 탐색 표시·새 평가 지표·버전과 다음 세대 재현을 검증한다.
- 실제 다중 시드 실험에서 점프·체공·점수·지지 시간과 인정 보행 거리를 각각 보고한다. 보행 거리 0을 성공으로 표현하지 않는다.

## 단계·점수·다양성·초기 자세 검증

- 실제 지지 시간 보상이 시간에 비례하고 공중 시간을 포함하지 않는다. 오래 서 있기보다 발 옮김·연속 전진 점수가 높고 최종 넘어짐 감점이 350 표시점인지 확인한다.
- 같은 보행 시간·거리에서도 자세 흔들림·미끄러짐이 큰 행동의 품질 보너스는 낮다. 정체·지속 낮은 몸통 높이로 실패 감점을 회피하지 못하고 짧은 높이 이탈은 허용한다.
- 누적 지지와 연속 지지를 구분하고, 3세대 달성·중간 실패 리셋·다음 세대 승급·수동 선택을 검사한다.
- 단계가 바뀌어도 이전 세대 점수·유전자를 재작성하지 않는다. 그래프와 CSV는 단계 차이를 보존한다.
- 같은 발 계열만 남지 않도록 다른 발 사용 후보를 부모에 포함하고 점프·계산 오류·심한 성능 저하는 제외한다.
- 실제 검증 World 세 개가 동일 유전자·서로 다른 초기 기울기를 쓰고 정지 중 World·기억이 바뀌지 않는다. 전체 실패·일부 통과·전부 통과와 자동 정지·유전자 보존을 각각 검사한다.
- 검증 종료 전에는 저장하지 않고 완료 상태만 v5에 기록한다. 손상된 단계 이력·승급 상태·점수 합계·검증 결과는 거절한다.
- 낮춘 테스트 기준의 실제 물리 fixture와 합성 합격 상태 검사는 기본 목표의 학습 성공으로 표현하지 않는다. 여러 시드의 실제 승급·걸음·거리·검증 통과를 별도로 기록한다.

- 0.5.1: 모든 단계에서 후진 1m당 150 표시점을 감점한다. 원점 복귀·공중·끌림·반대 자세·미세 후진으로 감점을 숨기지 못하며 실제 전진에만 큰 거리/지속 보너스를 준다. reward v2의 v5 파일을 현재 실험 상태를 유지하며 거절한다.

- 0.6.0: 정지 센서에서도 무작위 시간 입력에 따라 토크가 지속 변화하고 같은 유전자는 동일 출력을 재현한다. 0연결은 토크0이다. 실제 12관절 토크·일시정지 시 시간 입력 보존을 검증한다.
- 균형은 15초 끝까지 timeout+연속 지지 기준이며 2초 후 넘어진 개체는 제외한다. 균형 평가를 전진 정체7초로 끝내지 않는다.
- 실패 반복·동일 단계5세대 정체·개선/승급·수동 확대 끄기·0% 변이별 계획, 2~60대 구성 합계, 실제 큰 유전자 변이·엘리트·선택 부모·범위·저장 재현성과 v5 거절을 검사한다. 실제 10/50세대 달성 여부는 여러 시드 진화 결과로 별도 보고한다.

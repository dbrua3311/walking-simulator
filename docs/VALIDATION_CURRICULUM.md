# 단계별 유전학습과 보행 점수 검증 — 0.5.0

2026-11-07 (Asia/Seoul). 사용자가 단계별 학습·행동 다양성 적용을 승인했고, 지지 시간 비례 가점·큰 넘어짐 감점·앞으로 발을 옮겨 걸음을 유지할 때 큰 점수를 요청했다. 물리·무작위 신경망 직접 토크 제어를 유지하고 평가·선발·검증을 추가했다. 기존 aple·race-simulator는 사용하지 않았다.

## 현재 구현

- balance→stepping→forward의 목표와 점수 비중을 구분한다. 기본 3세대 연속 조건 달성 후 다음 세대부터 승급한다. 완료 세대의 점수는 바꾸지 않는다.
- 안정된 발 지지 시간만 선형 가점한다. 실제 발 들기·앞 이동·착지, 사용 발 다양성, 인정 거리, 자세/미끄러짐 품질을 곱한 전진 지속 시간에 보상한다. 최종 단계의 거리·전진 지속 비중은 85%, 서 있기만 하는 지지 보상은 최대 3%다.
- 넘어짐은 단계별 100/120/350 표시점, 정체는 20/40/100 표시점을 감점한다. 비행·수직 운동·옆 이동·회전·에너지 벌점도 유지한다. UI의 ×1,000 환산과 실제 평가 가중치 변경을 구분한다.
- 낮은 몸통 높이가 0.35초 이상 지속되면 fallen이다. 큰 넘어짐 벌점을 피하려 낮은 자세로 정체 종료하는 반례를 차단한다. 잠시 낮아졌다 회복하는 동작은 허용한다.
- 자동 부모 5대 중 상위 3대와 다른 발 사용/동작 후보 최대 2대를 고른다. 성능 하한·유효성 필터와 순위순 대체를 사용한다. 수동 부모는 바꾸지 않는다.
- 전진 후보는 독립 3World에서 기준·좌우/앞뒤의 작은 초기 기울기를 바꿔 재평가한다. 동일한 학습 유전자를 쓰고 이후 자세 보정을 하지 않는다. 모두 통과해야 자동 정지·검증 우승을 보존한다. 일부 실패는 계속 탐색한다.
- 검증 단계도 짧은 Worker 계산 묶음으로 진행하며 정지/재개 시 World·기억을 유지한다. 주 평가 tick과 검증 시간을 분리한다. 저장은 검증 완료 후 처리한다.
- 보행 점수 그래프는 현재 단계의 기록만 표시한다. CSV에 단계와 달성 지표를 추가한다. v5 JSON은 승급 대기·연속 달성·점수 내역·검증 우승을 보존하고 이전 v1–v4와 섞지 않는다.

자세한 임계값·점수식은 README와 ARCHITECTURE를 따른다. 특정 다리 순서·보행 주기·발 목표 경로·IK·자세 복원 제어·성공 유전자 주입은 추가하지 않았다.

## 자동 검사

- 물리·신경망·유전·저장·단계 전환 검사 93개 통과. 점수 합계·단계 이력·시간 범위 위조와 승급 후 기본 지지 능력 보존 반례도 포함한다.
- 실제 지지 시간의 선형 가점, 서 있기 대비 큰 보행 보너스, 단계별 넘어짐 감점, 흔들림/미끄러짐 품질, 여러 발·전진의 승급 조건과 중간 실패 리셋을 검증했다.

- 실제 물리와 낮춘 테스트 기준(balanceSeconds=0.1, promotionGenerations=1)으로 승급 예약·저장 복원·다음 세대 전환을 검사했다. 기본 2초·3세대 기준 달성을 주장하지 않는다.

- 지지 합계 조건 설명을 화면에 보완한 후 관련 승급 브라우저 검사 1개도 재통과(9.7초)했다.

## 0.5.1 후진 누적 감점 변경

2026-11-07. reward는 curriculum-progress-v3다. 이전에는 후진이 접지 전진 실적을 줄였지만 별도 누적 감점은 없었다. 이제 세계 +x의 반대 방향으로 이동한 거리 합계에 내부 0.15/m, 화면 150점/m를 모든 단계에서 감점한다. 공중·끌림·몸통 방향과 무관하게 세며, 다시 앞으로 가도 이미 받은 후진 감점을 취소하지 않는다. 미세한 후진에는 실제 거리만큼만 감점한다. 최종 전진 최대 450점·안정 보행 지속 최대 400점은 유지한다.

완료 저장은 기존 score.penalty에 후진을 포함하므로 형식은 v5를 유지하고 appVersion=0.5.1 및 rewardVersion을 구분한다. 이전 0.5.0 / reward v2의 v5 파일은 점수 혼합 없이 새 실험을 안내하며 거절한다. 원본은 보존한다.

## 배속 후속 수정

2026-11-09. 최초 검사는 명령 확인값에 집중해 처리 한계에서 배속들이 비슷하게 보이는 문제를 놓쳤다. 기본20대 자동 학습 실측에서 요청1/8/128의 중앙 처리량은 각각 약0.45/0.54/0.77배였으며 세대·생존 개체 수에 따라서도 달라졌다. 이는 동일 부하 성능 비교가 아니므로 최적화 향상률로 해석하지 않는다.

×0.1~×0.5 저속과 실측 처리 한계 안내를 추가하고 고배속 화면 갱신/스냅샷 빈도를 줄였다. 누적 실제 physics step 시간으로 저속→실시간→저속을 검증한 결과0.0915→0.4881→0.0974배였다. 자동 학습은 계속 유지했고 명령 숫자만 비교하지 않았다. 관련 브라우저4개(정지/재개·좁은 화면·명령 응답·실제 진행량)와 최종 타입/빌드 통과. 실측 로그는 USB artifacts/speed-e2e.log 및 배포 폴더speed-before.json이다.

## 실행 범위와 남은 확장

현재 파일 복원은 완료 세대 경계만 지원한다. 주행 중 자동 정지는 World를 메모리에 유지한다. 브라우저를 닫은 뒤 주행 중간의 물리 solver 상태까지 파일로 정확히 복원하는 기능은 후속 확장이다.

설계의 전체 권장 실험인 10시드×100세대는 아직 수행하지 않았다. 고급 접촉 편법·장시간 메모리 프로파일링·여러 브라우저 간 수치 차이의 전체 검증도 후속 작업이다. 현재 수치는 구현한 2D 측면 모델의 측정 결과다.

메인 Ubuntu에 새 Node나 npm을 설치하지 않았다. 기존 외부 파티션 Node를 읽어 사용했고, 소스·node_modules 약 192MiB는 별도 파티션, Chromium·패키지 캐시 약 918MiB와 실험·빌드·화면 결과는 USB에 저장했다.

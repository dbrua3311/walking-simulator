# 0.17.0 챔피언 제거 검증

2026-11-09. 보행 성능 성공 보고가 아니라 규칙·UI 변경 검증이다.

- 여섯 제어기에서 실제 평가 후 다음 세대champion/elite가0개이고 최고점 DNA의 자동 복사가 없는지 검사했다. 완료 파일을 다시 파싱하고 재개했을 때 같은 새 규칙의 다음 유전자/난수가 재현되는지도 검사했다.
- 수동 선택에서 제외한 최고점 개체를 몰래 넣지 않는다. 최고점을 균형 보존 명칭으로 우회 복사하는 것도 차단했다. 기존 안정 착지 탐색 계보 보호는 별도 기준으로 검증한다.
- 이전 연산자 회귀는preserveChampion=true를 명시한 역사적 경로로 보존한다. 실제앱의다음evolve는false다. 구파일은당시완료기록으로파싱하고다음세대부터전환한다.
- 지원되는최소4대/최대60대공통CMA의첫표본ID1과전체부모수60을검증했다.2대는기존일반GA경로를쓴다.
- 전체단위검사에서나온의도된보존규칙기대값을새규칙으로갱신했다.최종영향파일검사3개39테스트및일반진화포함2개47테스트통과,타입/빌드/diff검사통과. 고유 단위 검사221개 범위를 확인했다.
- 브라우저는전체16개범위를확인했으며,보존슬롯변경에따른변이11/5/2/2구성과점수/저장검사는수정후각각재실행통과했다.20대모두수동선택한부모에서변이하며챔피언은0개다.
- 개체별표시점수는실제저장fitness×1000과비교했고,시간진행에따라변하는지도확인했다.금색챔피언/별/elite강조는표시하지않는다.넓어진화면·기록접힘·모바일·저장복원·자동학습배속진행량회귀를유지했다.

로그와스크린샷은USB의walking-simulator/artifacts/no-champion-*.log와test-results에보존한다.후보의점수와실시간표시는실제평가이며,자동원본보존을없앤것을보행성공으로해석하지않는다.

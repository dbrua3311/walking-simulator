# Walking Simulator

실제 3D 강체 물리와 유전 알고리즘으로 사족보행 로봇의 보행을 학습하는 독립 프로젝트. 현재 앱은 **0.15.0**이다. 아직 네 발의 지속 전진과 최종 3조건 재검증을 통과한 정책은 확인하지 못했다.

- GitHub: [dbrua3311/walking-simulator](https://github.com/dbrua3311/walking-simulator)
- 소스·Git·의존성: `/mnt/extra/walking-simulator`
- 실험·캐시·브라우저·빌드·내보내기: `/mnt/piper-usb/walking-simulator`
- 기존 aple 계열과 race-simulator 프로젝트는 수정·이동·복사하지 않는다.
- 화면은 한국어이며, 제품명은 Walking Simulator다.

## 실행

```bash
cd /mnt/extra/walking-simulator
bash scripts/run.sh run dev
```

**http://127.0.0.1:5186/** 에 접속한다. 새 체크아웃의 의존성 설치는 `bash scripts/run.sh ci`다. 별도 파티션과 USB 마운트가 필요하며 메인 파일시스템으로 자동 대체하지 않는다. Node는 기존 별도 파티션 설치를 사용하고 홈의 전역 캐시 설정을 바꾸지 않는다.

업데이트 후 **새 실험 적용 → 자동 학습 시작**으로 새 기준을 사용한다. 이전 파일을 불러오면 이전 제어기·보상·성공 기준을 그대로 재개한다.

## 동작과 조작

기본 20대를 5×4 화면에서 동시에 관찰한다. 개체마다 독립된 Rapier 물리 공간에서 몸통과 네 다리, 12관절을 계산한다. 개체 수는 2~60대로 설정할 수 있다. 개체 수가 늘면 계산량도 증가한다.

- **실행 / 재개**: 한 세대를 평가한다. 평가 후 칸 클릭·드래그 또는 순위표에서 부모를 고른다.
- **결정완료**: 선택한 부모로 다음 세대를 만든다. 수동 제외한 부모를 강제로 넣지 않는다.
- **자동 학습 시작**: 평가·부모 선택·진화를 반복한다.
- **자동 학습 정지**: World·자세·신경망 기억을 보존하고 일시정지한다.
- 평가가 끝난 개체만 옅은 회색으로 표시한다. 단순 일시정지는 회색 처리하지 않는다.
- 유전자 검사창에서 실제 관절 토크·부모·변형된 값을 확인한다. 토크는 매 물리 tick 다시 계산한다.

## 보행을 미리 정하지 않는 학습

네 다리 각각 어깨·엉덩이·무릎 3관절, 총 13강체·12모터를 사용한다. 신경망이 실제 센서와 시간 입력을 받아 각 관절의 토크를 직접 출력한다. 보행 순서·발 경로·IK·목표 관절 각도·몸통을 미는 힘·사전 학습 정책은 넣지 않는다.

기본은 **방향 감각이 있는 44개 유전자** 모형이다. 같은 종류의 관절끼리 규칙을 공유해 탐색할 연결 수를 줄이되, 각 모터는 자신의 각도·속도와 다리별 독립 시간차에 반응한다. 시간차 네 개·주파수·모든 연결은 난수로 시작한다. 발 순서는 지정하지 않는다. 기준 전진 방향과의 차이·좌우 위치도 관측하며, 보정 연결의 부호와 크기는 유전학습으로 결정한다. 기본 부모 수는3개다.

**새 실험 적용 → 자동 학습 시작**으로 현재 모형을 사용한다. 균형 감각 → 네 발 주기 → 반복 유지 → 직진 다듬기 순으로 실제 성과에 따라 탐색을 바꾼다. 반복 유지에서도 세 관절종 모두의 시간 연결·주파수·네 다리 시점은 계속 진화한다. 실제 보행8초·연속3초가 되기 전에는 반복을 더 배우며, 최종 성공은 아래의 더 엄격한 별도 기준으로 검사한다. 새 위치 감각의 변이는 몸통 회전속도 감각과 토크에 미치는 크기가 달라 별도의 폭을 사용한다. 수동 부모·교차·0/100% 변이 설정도 지원한다.

신경망 구조에서 공통 규칙38개, 좌우 다리의 해부학적 방향을 맞춘 실험용44개 또는 기존 순환망541/565/589개를 선택할 수 있다. 실험용44개는 좌우 관절과 몸통 감각의 부호만 다리 구조에 맞춰 공유하며, 보정 계수와 발 순서는 여전히 학습한다. 같은44개라도 기존 모형과 좌표 해석이 다르므로 별도 모형·버전으로 저장한다.589개는541개 순환망에 관절 각도/속도 직접 연결24개·모터별 직접 시간 연결24개를 더한 구조다. 이전 파일은 당시 모형으로 그대로 복원한다. 새 기본도 아직 최종3조건 보행 검증을 통과하지 못했다.

초기화 기본은 **완전 무작위**다. 선택 가능한 약한 균형 편향은 공통 조립 자세의 정적 하중으로 초기 출력 편향 분포만 이동한다. 565개·589개 구조에서는 초기 감각 연결의 각도 기여도 함께 조건화한다. 강도1일 때 초기 토크 분포를 보존하면서 감각 연결을 탐색할 수 있다. 학습된 자세를 복사하거나 런타임에 각도 목표를 적용하지 않는다.

## 균형에서 네 발 전진까지

| 단계      | 새 실험의 통과 조건                                                                                                           |
| --------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 균형 유지 | 평가 15초 끝까지 생존, 연속 안정 지지 2초, 관절 가동 여유를 유지한 연속 지지 2초·합계 12초, 종료 관절 가동 여유 80% 이상      |
| 발 옮기기 | 정상 지지 합계 2초, 네 발 각각 2걸음·총 8걸음, 접지 전진 0.05m, 연속 보행 1초, 15초 끝까지 유지하며 종료 때도 네 발 반복 보행 |
| 연속 전진 | 인정 거리 1m, 유효 보행 합계 10초, 연속 전진 5초, 네 발 각각 2걸음, 판정 순간도 보행 중                                       |

앞 두 단계는 3세대 연속 통과한 뒤 **다음 세대부터** 바뀐다. 같은 단계·보상끼리 점수 그래프를 비교한다. 거리 그래프는 모든 단계의 인정 거리를 표시한다.

한 걸음은 정상 지지에서 시작해 발을 **35mm 이상 들고, 70ms 이상 공중에 두고, 세계 +x 방향으로 18mm 이상 옮겨 착지**해야 인정한다. 초기 낙하·전신 점프·바닥 끌기는 걸음이 아니다. 보행 시간과 거리는 정상 자세·발 2개 이상 지지·낮은 미끄러짐·네 발 모두 최근 3초 안 걸음을 만족한 전진 구간만 적립한다. 새 실험에서는 각 발이 몸무게의5% 이상을 실제 접촉 하중으로 받쳐야 지지로 센다. 미끄러짐도 구형 발 중심이 아닌 바닥 접촉점의 속도를 실제 하중으로 가중해 평가한다. 바닥 가까이 지나가는 무하중 발을 지지 발처럼 평균내지 않는다. 발의 순서나 상대 위상은 지정하지 않는다.

짧은 접촉 공백 0.1초는 연속 구간을 즉시 끊지 않되 그 시간을 보행 시간에 더하지 않는다. 새 실험의 최종 보행 합격은 네 발 동시 체공을 최장0.02초로 제한한다. 이보다 긴 동시 체공을 반복하는 동작은 공백 허용으로 연결되더라도 성공으로 인정하지 않는다. 이전 파일의 누락된 체공 기준은 당시 점프 한도를 유지하고, 새 실험 적용 시 새 기준을 사용한다. 옆으로 흔들린 거리의 누적 대신 최대 코스 이탈 0.2m·방향 이탈 0.35rad로 판정한다. 누적 옆이동·회전의 작은 점수 감점은 유지한다.

최종 후보는 같은 유전자로 기준 자세와 두 미세 기울기 조건에서 다시 평가한다. **세 조건 모두** 거리·보행 시간·연속 전진·네 발 반복·체공·좌우 이동·회전 기준을 통과한 경우만 성공으로 표시하고 자동 정지한다.

## 점수와 진화

지지·발 옮김·전진·연속 보행·감점을 따로 표시한다. 표시 점수는 내부 점수의 1,000배다. 넘어짐은 발/전진 단계에서 350점 감점하고, 후진은 누적 1m당 150점을 모든 단계에서 감점한다. 다시 전진해도 후진 감점은 취소되지 않는다.

새 `mobile-curriculum-v8`은 낮은 자세로 관절 끝에 기대는 동작을 구분한다. 관절 가동 여유가 있는 접지 자세에 가점하고, 관절 끝을 지속적으로 밀어도 기계적 일이 거의 0이던 문제를 별도 토크 감점으로 보완한다. 반복 발 옮김은 초반 한두 걸음 뒤 정지하는 동작보다 더 높은 보상을 받는다. 작은 발 이동의 중간 보상도 실제 앞으로 옮긴 뒤 0.15초 안정 재착지가 확인되어야 한다.

**자동 균형 탐색**의 기본은 부모 가중 재조합과 공분산 Gaussian 변이다. 현재 우승 1대는 그대로 보존한다. 우승과 별개로 균형 기준을 통과한 개체가 있으면 그 개체도 보존하고, 나머지를 실제 물리로 평가해 다음 탐색 분포를 갱신한다. 초기 토크와 관절 감각 연결을 분리한 36차원 좌표를 사용한다. 우승 복사 외의 평가 부모를 사용하며 분포·경로·난수·실제 부모 유전자를 저장한다. 변이율과 폭은 탐색 강도에 반영한다.

수동 선택·교차율이 0%가 아닌 경우·변이율 0/100%·자동 탐색 확대 끄기·발/전진 단계에서는 개별 교차·변이를 사용한다. 0%는 변이하지 않고 100%는 전체 유전자를 바꾼다. 589개 발/전진의 기본 작은/중간/큰 변형 폭은 허용 범위의 0.1/1.5/8%다. 작은 변이만 반복하지 않고, 일부 자식은 한 다리의 시간 연결을 함께 바꾼다. 각도 감각과 시간 연결 변화가 출생 순간에 주는 영향을 편향에서 상쇄하되 의도적인 편향 변이는 보존한다. 교차는 물리적 의미가 같은 감각·시간 연결을 대상으로 한다. 다리의 실제 움직임과 균형은 여전히 물리로 평가한다.

발/전진 단계에서는 점수 우승과 별도로 실제 균형을 통과한 계보, 새로운 발 동작을 개선한 탐색 계보를 보존할 수 있다. 승급 직후부터 작은 보행 변이를 적용한다. 수동 선택에서 제외하면 해당 보존 자리도 일반 변이로 돌린다. 총 개체 수는 유지한다.

## 현재 측정 결과와 한계

이전589개 모형의 최신 변이·선발 방식도 3시드×50세대에서 모두 지속 보행을 얻지 못했다. 20개체만의 문제로 단정하지 않고 탐색 구조를 줄인 공통 제어기를 추가했다.

별도 38개 구조의 완전 무작위 20대·seed2026 실험에서는 10세대에 건강한 15초 균형이 나왔고, 41세대에 실제 보행 8초를 넘었다. 실제 70세대 개체는 네 발 [9, 9, 10, 9]걸음·연속 보행 약 9.575초·인정 전진 3.523m였다. 하지만 좌우 이탈 1.478m로 기준을 벗어났고 한 기울기 조건에서 넘어졌다. **최종 3조건 검증을 통과한 정책은 아직 없다.** 이 개체를 새 1세대에 주입하지 않는다.

44개 모형으로 연결을 추가한 직후에는 세 초기 자세의 모든 물리 프레임이 원래 개체와 정확히 같음을 검증했다. 이후 실제 방향 보정 진화와 앱 통합본의 새 무작위 실험을 별도로 평가한다. 초기44개 통합본은70세대 최대 보행2.717초였고, 실제20세대부터 시간 연결 탐색을 넓힌 비교는70세대 최대4.292초·0.509m까지 개선됐지만 최종 실패였다. 현재 기본44개/v3의 완전무작위70세대 비교는 최대 보행3.367초로 최종 실패였다. 실험용 해부학44개도 같은70세대 개체의 보행5.667초·연속0.9초·1.190m였지만 좌우2.978m 이탈로 실패했다. 두 결과를 합쳐 성공으로 표시하지 않는다. USB 연구에서 관절 감각 변이와 실제 세 자세 평가를 계속 비교한다. 10세대 균형·50세대 보행은 목표이며 보장 수치가 아니다. [실제 검증 기록](docs/VALIDATION_ADAPTIVE.md)에 실패·실험 버전·출처를 함께 남긴다.

0.14.0은 단위197개·브라우저13개를 통과했다. 현재0.15.0은 실제 하중 측정·순수 구름/미끄러짐 구분·새 파일 버전 검사를 포함한 단위201개·브라우저13개·타입·빌드를 통과했다. 공통38개·방향44개·해부학44개 구조의 선택·저장·복원과 이전 체공 기준 보존/새 실험 전환을 포함한다. 자동 검사 통과와 실제 학습 성능은 구분한다.

## 저장과 검증

완료 세대를 JSON v6로 저장한다. 단계·기준·유전자·부모·점수·난수·재검증과 공분산 탐색 상태를 포함한다. 물리 계산 도중 요청한 저장은 세대 종료까지 예약된다. 일시정지 중 예약했다면 재개해야 저장된다. JSON은 완료 세대를 복원하며, 실행 도중 solver 상태를 파일로 복원하지 않는다.

기존 565개 완료 체크포인트는 명시적 확장 도구로 시간 연결 24개를 0으로 추가할 수 있다. 원본·SHA·이력·난수·전환 세대를 보존하고 다음 세대부터 새 연결을 진화한다. 학습한 개체를 새 무작위 1세대에 넣지 않는다. 일반 불러오기는 구조를 바꾸지 않는다.

파일 선택기에서 USB를 선택한다. 선택기를 지원하지 않는 브라우저는 다운로드 기본 폴더를 USB로 정한다. 구 541개 형식6 파일은 당시 제어기·점수·종료 기준을 유지한다. 이전 v1~v5의 호환되지 않는 구조는 설명과 함께 거절하며 원본은 보존한다.

```bash
bash scripts/run.sh test
bash scripts/run.sh run build
bash scripts/run.sh run test:e2e
SEEDS=2026,2027,2028 GENERATIONS=50 bash scripts/run.sh run experiment
CONTROLLER_MODEL=shared-direction SEEDS=2026 GENERATIONS=70 bash scripts/run.sh run experiment
RESUME=/mnt/piper-usb/walking-simulator/experiments/실험폴더/seed-2026.json GENERATIONS=100 bash scripts/run.sh run experiment
```

재개의 목표 세대는 최종 세대 번호다. 원본·SHA-256·소스·버전·이력을 새 USB 폴더에 보존하고 다음 세대부터 이어간다. 배운 정책을 1세대에 넣어 성과를 부풀리지 않는다. CLI는 SIGINT/SIGTERM 요청 시 현재 세대를 마친 뒤 저장·종료한다. 브라우저 검사는 전용 5187 포트를 쓰며 개발 서버 5186을 재시작하지 않는다.

구조는 [ARCHITECTURE.md](docs/ARCHITECTURE.md), 저장 위치는 [STORAGE.md](docs/STORAGE.md), 초기 범위는 [PROJECT_OVERVIEW.md](docs/PROJECT_OVERVIEW.md)에 있다. 초기 설계안과 과거 버전 검증은 현재 보행 성능의 증거로 사용하지 않는다.

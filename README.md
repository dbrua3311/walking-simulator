# Walking Simulator

3D 물리 시뮬레이션과 유전 알고리즘으로 사족보행 로봇의 움직임을 학습하는 독립 프로젝트다. 기본 20대가 무작위 유전자에서 출발해 실제 물리 평가, 부모 선발, 재조합·돌연변이를 반복한다.

현재 버전은 **0.17.0**이다. 안정 착지 보상, 챔피언 자동 보존 제거, 실시간 점수 표시와 간단해진 학습 화면을 반영했다. **네 발의 지속 전진과 최종 3조건 검증을 모두 통과한 정책은 아직 확인하지 못했다.**

- 저장소: [dbrua3311/walking-simulator](https://github.com/dbrua3311/walking-simulator)
- 공개 시연: [Walking Simulator 실행](https://walking-simulator-demo-20261109.bentbrush6.chatgpt.site)
- 화면 언어: 한국어

공개 시연은 Ubuntu 설치 없이 브라우저에서 실행한다. 물리 계산은 접속한 기기에서 수행하므로 기기 성능에 따라 속도가 달라진다. 배포 링크는 주소를 유지해 갱신할 수 있지만, 로컬 파일 수정이나 GitHub push만으로 자동 갱신되지는 않는다. 새 빌드의 별도 배포가 필요하다.

## 로컬 실행과 저장 위치

```bash
cd /mnt/extra/walking-simulator
bash scripts/run.sh ci       # 처음 의존성을 설치할 때
bash scripts/run.sh run dev
```

개발 화면은 **http://127.0.0.1:5186/** 이다. 위 명령은 현재 Ubuntu 개발 환경의 별도 파티션과 USB 마운트를 전제로 한다. 다른 PC에서는 해당 경로와 Node 설치 위치를 확인해야 한다.

| 용도 | 저장 위치 |
| --- | --- |
| 소스·Git·프로젝트 의존성 | `/mnt/extra/walking-simulator` |
| 실험·체크포인트·내보내기 | `/mnt/piper-usb/walking-simulator` 아래 전용 폴더 |
| 캐시·브라우저·빌드·테스트 결과 | 같은 USB의 `cache/`, `artifacts/`, `tmp/` |

`scripts/run.sh`는 마운트를 확인하고 프로젝트 전용 캐시와 임시 경로를 지정한다. 장치가 없으면 중단하며 메인 Ubuntu 저장소로 대체하지 않는다. Node는 별도 파티션의 설치를 사용하며, 필요하면 `WALKING_NODE_BIN`으로 실행 파일 디렉터리를 지정한다. 자세한 운영 기준은 [STORAGE.md](docs/STORAGE.md)에 있다. 기존 aple 및 Race Simulator 프로젝트는 수정하지 않는다.

## 화면과 사용 방법

기본 화면은 왼쪽 제어와 넓은 로봇 화면으로 구성된다. 20대를 5×4 칸에서 동시에 관찰하며 개체 수는 2~60대로 설정할 수 있다. 각 칸에는 **실시간 적합도×1,000 점수**를 표시한다. 평가가 끝난 개체만 옅은 회색으로 바뀌며 전체 일시정지는 회색 종료와 구분한다.

1. **실험 설정 → 새 실험 적용**으로 현재 기본 보상과 평가 기준의 실험을 시작한다. 기존 기록이 필요하면 먼저 JSON으로 저장한다.
2. **자동 학습 시작**을 누르면 평가·부모 선발·다음 세대 생성을 반복한다.
3. 수동으로 진행하려면 **실행 / 재개**로 한 세대를 평가하고, 칸 클릭·드래그 또는 자동 선택으로 부모를 고른 뒤 **결정완료**를 누른다.
4. **자동 학습 정지**는 현재 물리 공간·자세·신경망 기억을 보존한다. 재개하면 이어서 진행한다.
5. **JSON 저장 / 불러오기**로 완료 세대를 보관하거나 이어간다.

실험 설정, 로봇 상세 수치와 유전자 검사, **학습 기준과 상세 기록**은 기본적으로 접혀 있다. 오른쪽 고정 학습 기록 패널은 없으며 기록·순위표·그래프는 상세 기록에서 펼쳐본다. 버튼과 패널은 Race Simulator 계열의 남색·청록 테마를 사용한다.

### 배속

자동 학습 중에도 **×0.1~×256** 요청 배속을 바꿀 수 있다. 화면은 Worker가 확인한 요청값과 실제 물리 진행 배속을 구분해 표시한다. 컴퓨터가 처리 한계에 도달하면 요청을 높여도 실제 속도 차이가 작을 수 있다. 느린 관찰에는 ×0.1~×0.5를 사용할 수 있다.

고배속에서는 화면 갱신을 5fps, 상태 전송을 4Hz로 낮춘다. 물리 계산의 기본 간격은 1/120초이며 평가 tick을 건너뛰지 않는다.

## 학습 원리와 로봇 구조

몸통 1개와 네 다리의 링크 12개, 총 **13강체·12관절**을 Rapier 3D로 계산한다. 각 다리는 어깨·엉덩이·무릎 3관절이며 개체마다 독립된 물리 공간을 사용한다. 신경망이 감각과 시간 입력에서 관절 토크를 매 물리 tick 계산하므로 출발 때 정해진 토크로 고정되지 않는다.

기본 제어기는 **`shared-direction` 44개 유전자**다. 같은 종류의 관절끼리 규칙을 공유하고 자신의 각도·속도, 몸통 감각, 전진 방향 오차와 좌우 위치에 반응한다. 연결 가중치, 주파수와 다리별 시간차는 무작위로 시작하며 부모의 유전자를 바탕으로 계속 변한다. 보행 순서·발 경로·IK·목표 관절각·몸통을 미는 힘이나 사전 학습 정책은 넣지 않는다.

기본 자동 탐색은 실제 부모의 가중 재조합과 Gaussian 돌연변이를 사용하는 공분산 탐색이다. 균형·발 주기·반복 유지·직진 연습에 따라 탐색할 좌표를 바꾸며, 시간 연결과 네 다리의 시간차도 계속 탐색한다. 수동 부모 선택, 교차율, 0/100% 변이, 자동 탐색 확대 끄기도 지원한다. 화면에서 선택한 부모를 몰래 다른 부모로 바꾸지 않는다.

선택형 제어기로 공통 규칙 38개(`shared-reflex`), 해부학 좌표 44개(`shared-anatomical`), 순환 신경망 541/565/589개가 있다. 같은 유전자 수라도 모형의 의미가 다르면 별도로 저장·복원한다. 565/589개 계열의 선택형 균형 탐색은 36차원 공분산 좌표를 사용한다. 구조와 연산자의 세부 사항은 [ARCHITECTURE.md](docs/ARCHITECTURE.md)에 있다.

초기화 기본은 **완전 무작위**다. 선택 가능한 약한 균형 편향은 출생 유전자의 초기 출력 분포만 바꾸며, 학습한 자세나 보행 패턴을 초기 집단에 주입하지 않는다.

## 점수와 부모 선발

새 실험의 보상은 **`settled-curriculum-v9`**다. 균형 단계의 지지·안정 착지·전진 비중은 **70/27/3**이며, 단순히 오래 서 있는 것 외에 실제 발 옮김이 안정적으로 이어지는지를 평가한다.

- **안정 착지:** 유효한 발 들기·전진·착지 뒤 0.2초 동안 실제 하중 접촉과 정상 자세·지지를 유지해야 인정한다. 초기 낙하, 바닥 끌기, 발만 들기, 착지 직후 붕괴에는 주지 않는다.
- **관측된 균형 회복:** 발이 공중일 때 증가하던 몸통 기울기가 유효 착지 뒤 줄어든 경우 추가 보상한다. 평가당 최대 2회, 최소 2초 간격과 새로운 전진 위치를 요구한다. 이것만으로 발이 낙상을 막았다는 인과관계를 판정하지는 않는다.
- **전진과 감점:** 전진·연속 보행을 평가하고 넘어짐·후진·점프·미끄러짐·방향 이탈·관절 끝을 계속 미는 토크 등을 감점한다. 후진은 누적 1m당 표시 150점을 감점하며 다시 전진해도 취소되지 않는다. 발/전진 단계의 넘어짐 감점은 350점이다.

**챔피언 규칙은 제거했다.** 최고점 개체의 원본을 자동 복사하는 고정 자리, 금색 몸통·오라·별·챔피언 카드는 없다. 좋은 부모를 선발해 재조합·변이하는 과정은 유지한다. 충분히 지지하면서 안정 착지를 개선한 탐색 계보와 최고점과 다른 균형 계보는 별도 조건으로 보호할 수 있다. 수동으로 제외한 부모는 보존하지 않는다.

표시 점수는 내부 적합도의 1,000배다. 점수가 높아지거나 일부 발을 옮겼다는 사실과 최종 보행 성공은 구분한다.

## 보행 판정과 최종 목표

아래는 기본 15초 평가의 새 실험 기준이다.

| 단계 | 통과 조건 |
| --- | --- |
| 균형 유지 | 평가 끝까지 생존, 연속 정상 지지 2초, 연속 가동 여유 지지 2초·합계 12초, 종료 관절 가동 여유 80% 이상 |
| 발 옮기기 | 정상 지지 합계 2초, 네 발 각각 2걸음·총 8걸음, 접지 전진 0.05m, 연속 보행 1초, 평가 끝까지 생존하며 종료 때도 반복 보행 |
| 연속 전진 | 인정 거리 1m, 유효 보행 합계 10초, 연속 전진 5초, 네 발 각각 2걸음, 판정 순간도 보행 중 |

앞 두 단계는 3세대 연속 통과하면 **다음 세대부터** 승급한다. 단계나 보상 체계가 다른 점수는 한 그래프로 이어 비교하지 않는다.

한 걸음은 정상 지지에서 출발해 발을 **35mm 이상 들고 70ms 이상 공중에 둔 뒤 세계 +x 방향으로 18mm 이상 옮겨 착지**해야 인정한다. 지지는 각 발이 몸무게의 5% 이상을 실제 접촉 하중으로 받쳐야 하며 미끄러짐은 발의 바닥 접촉점 속도로 계산한다.

보행 시간과 거리는 정상 자세·발 2개 이상 지지·낮은 미끄러짐·네 발 모두 최근 3초 안 걸음 이력을 만족한 전진 구간만 적립한다. 짧은 접촉 공백 0.1초는 연속 구간을 즉시 끊지 않되 적립 시간에 더하지 않는다. 최종 합격에는 동시 체공 최장 0.02초, 최대 좌우 이탈 0.2m와 방향 이탈 0.35rad 제한도 적용한다.

최종 후보는 같은 유전자로 기준 자세와 두 미세 기울기, **총 3조건을 다시 평가해 모두 통과해야** 성공으로 표시하고 자동 정지한다. 서 있기, 한 발 반복이나 세 발 이동은 최종 네 발 전진 성공이 아니다.

## 현재 검증 결과와 남은 과제

2026-11-09 기준 0.17.0 소스의 전체 검증 결과다.

| 검사 | 결과 |
| --- | --- |
| Vitest | 10개 파일, 221개 테스트 통과 |
| TypeScript 타입 검사·프로덕션 빌드 | 통과 |
| Playwright | 16개 테스트 통과 |
| 실제 자동 학습 배속 변경 | 저속→실시간→저속 약 ×0.089→×0.539→×0.096 확인 |

이는 프로그램 동작 검증이며 보행 학습 성공을 뜻하지 않는다. 실측 배속은 해당 기기의 당시 결과로, 요청 ×1이나 ×256의 처리 성능을 보장하지 않는다.

이전 별도 38개 구조의 무작위 20대 실험에서는 70세대에 네 발 [9, 9, 10, 9]걸음·연속 보행 약 9.575초·인정 전진 3.523m가 나왔다. 하지만 좌우 이탈 1.478m와 한 기울기 조건의 넘어짐으로 최종 실패했다. 현재 기본 44개 구조의 성과와 합치거나 새 1세대에 주입하지 않는다.

안정 착지 보상은 같은 초기 DNA·seed2026·20대·15초의 v8/v9 각 10세대를 비교했다. v9에서 안정 착지 1회와 개선된 탐색 계보의 보존을 확인했지만 두 실험 모두 최장 유효 보행은 0초였다. 이 비교는 챔피언 제거 전 0.16.0 실험이므로 현재 0.17.0의 장기 학습 성능을 입증하지 않는다.

남은 과제는 현재 규칙으로 여러 시드의 장기 학습을 평가하고, 네 발 반복·직진·기울기 내성을 함께 만족하는 정책을 얻는 것이다. 10세대 균형·50세대 보행은 목표이며 보장하지 않는다. 상세 기록은 [안정 착지 검증](docs/VALIDATION_LANDING.md), [챔피언 제거 및 최종 전체 검사](docs/VALIDATION_NO_CHAMPION.md), [이전 실험 기록](docs/VALIDATION_ADAPTIVE.md)에 있다.

## 저장·복원과 실험 실행

JSON v6에는 완료 세대의 유전자·부모·점수·단계·평가기준·난수·공분산 탐색 상태와 재검증 정보를 저장한다. 실행 중 저장 요청은 세대 종료까지 예약하며 일시정지 중이라면 재개해야 저장된다. 파일은 완료 세대를 복원하고 실행 도중의 물리 solver 상태를 복원하지 않는다.

이전 파일은 당시 제어기·보상·평가기준과 완료 기록을 유지한다. 다만 **다음 세대 생성부터 챔피언 자동 복사를 해제**한다. 현재 보상을 쓰려면 기존 파일을 단순 재개하는 대신 **실험 설정 → 새 실험 적용**을 선택한다. 호환되지 않는 예전 v1~v5 파일은 설명과 함께 거절한다.

저장 위치는 USB를 선택한다. 파일 선택기를 지원하지 않는 브라우저는 다운로드 폴더를 USB로 지정한다. 대량 실험을 브라우저 저장소에 자동 보관하지 않는다.

```bash
bash scripts/run.sh test
bash scripts/run.sh run build
bash scripts/run.sh run test:e2e

# 새 무작위 집단의 다중 시드 평가
SEEDS=2026,2027,2028 GENERATIONS=50 bash scripts/run.sh run experiment

# 완료 파일에서 최종 100세대까지 이어서 평가
```
